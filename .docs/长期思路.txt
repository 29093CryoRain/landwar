经济+科技系统分化为经济+工业+科技系统:{
    文本展示时, 经济, 工业, 科技应像一个字符(比如金币符号, 齿轮符号, 原子模型符号)一样渲染.
    经济与领地面积, 首都是否存在, 城市量有关.
    工业与城市量, 首都是否存在有关.
    科技与最高城等级, 首都是否存在, 城市量有关.
    经济通常能带来短期增益, 工业能带来中期增益, 科技是长期增益.
    一次性技能主要需要经济. 产兵主要需要经济和工业. 可放置建筑主要需要工业. 科技升级需要科技.
    另外有"技艺"系统:{
        基于经济生产速率(经济/tick).
        是一些词条, 有不同的增益, 也通常附带兵种造价增加的减益, 例如"普通兵速度+5%, 造价+1%"
        玩家可选择一些词条, 在技艺规划区, 词条线性排列成一个表, 每个词条需要一些经济生产速率.
        技艺系统根据势力经济生产速率和词条表, 一个临时变量赋值为经济生产速率, 
            从第一个词条开始, 若临时变量高于此, 则应用此词条, 临时变量-=词条所需的经济生产速率, 然后检查下一个词条.
            也就是说, 经济生产速率越高, 能生效的词条越多, 但经济生产速率不会因此降低.
            由于经济生产速率经常随着领地的变动而变动, 这种玩家排布词条表的方案, 使得玩家能让最重要的词条排在前面, 在大多时间下都能生效.
            词条作用于兵产出的时刻, 兵产出后即使词条变了, 这个兵身上的buff还是不变的.(待定)
        技艺系统通常是些简单,不复杂的词条.
        这个系统可以使得在游戏后期, 经济收入很高时, 可以将经济转化为兵种质量, 而不是简单地转化为兵种数量.

河流系统：{
    河流是地块的顶点和边的集合。通常是这些边首尾相连。
    代码基础：先维护地块顶点的几何关系接口，重点是邻点接口，或者相关的几何接口。信息可以根据地块的顶点来建立，只需创建地图时建立一次。
    局内效果：不影响其他地形，只影响兵的运动，兵碰到河时有概率穿过，概率定义为"过河概率"，其他情况反弹。过河时不减速。与其他概率反弹同时生效时：先判定河，若通过再判断山，若通过再判断敌方地块（此阶段即使判定为反弹，也可占领该敌方地块，前几个阶段则不可以）。河的边的两个邻块不能有海
    渲染效果：粗的纯黑线。注意不能覆盖城/首都图标，不能覆盖城基建地块边界线。
    地图编辑器生成：地图信息新增河流部分，新增一个河流按钮，选择时，鼠标点击或拖拽时，计算鼠标点在原图上落在哪个地块，然后计算离哪条边最近，记录为河。
    随机地图生成：玩家交互界面需输入河流密度(参考城密度, 山密度等现有功能的输入交互逻辑)，生成时，河流密度*地图总格数得到河流数量，生成完山地后，尝试随机进行河流数量次操作：随机抽取一个山地，随机取其一个顶点，从这个点作为河流源点生成河流：每次按某种概率分布取上个点的邻点作为下一个点，两点之间是一段河。这个概率分布，是基于原始海拔信息在这个点附近的梯度（包括方向和大小），以及这个点的几个几何邻点的方向（只考虑方向，不考虑距离）得到的（可以考虑梯度与候选方向单位向量做内积，之后做个含参数的softmax），但还需额外去掉已在本次生成的河流上的点（例如上一个点，或者河流绕了一圈的情况）（如果点是其他次生成的河流，则概率分布不受影响，但选择这个点后直接停止本次河流生成，相当于河流支流交汇），如果所有邻点都不可用，则直接终止本次河流生成（相当于得到内陆河），进行下一次生成。如果选取的点是海洋地块的顶点，则做完这一段就终止本次河流生成。如果这个过程需要定一些参数，请将其置config.jsonc，我调整并观察效果。如果山地格数量不够，选择非山地的陆地格。随机抽取山地格这点，可能某些功能已实现随机顺序处理地块，或许可跟着这部分功能来生成河流。
    需做好相关接口, 日后可能有其他建立在地块边上的结构.
    2026.9.25 已完工.

战场迷雾系统：{
    定义单元视野，是一个兵/一个领土地块/一个城/一个建筑（目前还没做建筑系统）的视野区域。每个都是以自身中心为圆心的圆形区域。暂定普通地块视野半径2，兵3，非首都城5，首都10。另外, 每个单位视野还有强度值，非0整数, 前文这些强度值都为1。
    定义势力视野：该势力的所有单元视野之并集，或者为了性能和游戏效果的其他某种运算得出的，或者某些模糊化处理。
    定义联盟视野：己方势力以及所有盟友势力的单元视野之并集或上述同种运算。
    玩家及NPC势力AI实际能看到的视野是联盟视野，如果无盟友则退化为势力视野。
    具体地，每个势力的视野运算时，只考虑己方的正强度值单位视野和敌方的负强度值单位视野。按1，-1，2，-2，3，-3...的顺序计算，负数相当于将已计算的视野范围变为不可见的。
    兵种/建筑: 侦察兵(半径15,强度2), 侦察塔(半径15,强度2), 影幕兵(半径12, 强度-2).
}
兵运动规范处理:{
    由于兵的运动中, 反弹现象仅出现在碰到地图格边缘的情况, 接下来将定义, 存在某些无法占领的格时, 兵将如何运动:
    1. 若原先所在格与目标格都是该兵不可占领的, 则不反弹, 匀速直线运动, 直接进入目标格.
    2. 若目标格是该兵不可占领的, 但原先所在的格可占领, 则反弹, 不占领.
    3. 若目标格是该兵可占领的, 原格是不可占领的, 则占领目标格且不反弹, 匀速直线进入目标格.

    目前已知的不可占领的格仅有海洋, 其符合上述规则, 并且多几个海洋特有的规则:
    1. 海洋中兵减速
    2. 目标格是海洋时, 有一定概率, 兵进入海洋; 一定概率反弹. 即使原先所在格是无法占领的.

    接下来将利用到这个规范, 开发一些新的机制:
    盟友势力, 己方不能占领盟友的地图格. 详见盟友系统.
    部分兵不能占领敌方势力的地图格. 以科技的形式, 做一个科技, 详见科技开发列表.txt 的"密集防御"词条, 把这个做出来.
}
