# 发行版导出指南

SDL2 + entt + ImGui 翻新版。所有命令用 PowerShell，工具链为 MSYS2 **UCRT64**
（`D:/application/MSYS2/ucrt64`，本机路径可在 `CMakePresets.json` 找到）。

## 0. 前置

- 已安装 MSYS2 UCRT64，含 SDL2 / SDL2_image / nlohmann_json / spdlog / EnTT / gtest。
- 项目根：当前仓库目录（文中用 `$SRC` 表示）。
- 产物目录：`D:\Documents\Projects\Project_landwar\landwar_发行版`（文中用 `$REL` 表示）。

建议从项目根目录打开 PowerShell，并先设置变量：

```powershell
$src = (Get-Location).Path
$rel = "D:\Documents\Projects\Project_landwar\landwar_发行版"
```

## 0.1 推荐流程：自动打包

完成构建后，用 `tools/package_release.ps1` 在独立目录生成发行包。脚本会复制运行时资源，递归解析
MSYS2 DLL 依赖，创建 `userdata/`，并可执行配置、无头和窗口截图验证：

```powershell
powershell -ExecutionPolicy Bypass -File "$src\tools\package_release.ps1" `
    -SourceDir $src -OutputDir $rel `
    -Msys2Bin "D:\application\MSYS2\ucrt64\bin" -Verify -VerifyWindow
```

加入 `-Build` 可先执行 Release 配置和编译。无桌面会话时省略 `-VerifyWindow`；其余手工步骤用于
排查或审阅包内容。

## 1. 单独编译 Release（不用 Debug）

```powershell
$cmake  = "D:/application/MSYS2/ucrt64/bin/cmake.exe"
$ninja  = "D:/application/MSYS2/ucrt64/bin/ninja.exe"
$src    = (Get-Location).Path

& $cmake -S $src -B "$src\build-release" -G Ninja `
    -DCMAKE_BUILD_TYPE=Release `
    -DCMAKE_CXX_COMPILER="D:/application/MSYS2/ucrt64/bin/g++.exe" `
    -DCMAKE_PREFIX_PATH="D:/application/MSYS2/ucrt64" `
    -DCMAKE_EXPORT_COMPILE_COMMANDS=ON

& $ninja -C "$src\build-release"
```

产物：`build-release\landwar.exe`（Release 约 3.9MB；Debug 那版约 63MB，不用于分发）。

## 2. 验证

```powershell
# 单元测试。发行前应检查为全绿；若失败，不能用旧 state_hash 掩盖失败。
& "D:/application/MSYS2/ucrt64/bin/ctest.exe" --test-dir "$src\build-release" --output-on-failure

# 确定性冒烟：headless 跑到指定位数，核对 state_hash
& "$src\build-release\landwar.exe" --headless --seed 42 --ticks 1000 --summary
```

> 注意：README 里写的基线 `state_hash`（如 `0x42d404e8ccc24bc4`）是 P10 前的旧值；
> 源码推进到 P11/P13–15 后哈希会变。以「Release 与 Debug 同参数跑出相同哈希」为准则，
> 即 Release 与当前源码态一致。

当前源码态已完成测试基线同步：Release 构建成功，`ctest` 共运行 441 项并全部通过，headless 1000 tick
成功。若配置或模拟行为后续有意变更，必须重新运行测试并同步黄金数据/语义基线记录。

## 3. 建发行版目录

```powershell

Copy-Item -LiteralPath "$src\build-release\landwar.exe" -Destination "$REL\landwar.exe" -Force
```

## 4. 拷 DLL（运行时依赖闭包）

`landwar.exe` 直接依赖 SDL2、SDL2_image、spdlog 及 GCC 运行时；SDL2_image 又把 AVIF/JPEG-XL/
PNG/TIFF/WebP 等编解码 DLL 硬链接进导入表，**不能删**，否则 SDL2_image.dll 加载失败。

用 `objdump -p` 递归展开依赖（排除 Windows 系统 DLL），把每个能
在 `ucrt64/bin` 找到的第三方 DLL 拷进 `$REL` 根目录，与 `landwar.exe` 同层：

```powershell
$bin = "D:/application/MSYS2/ucrt64/bin"
$od  = "$bin/objdump.exe"
$sysRe = '^(KERNEL32|USER32|SHELL32|ADVAPI32|GDI32|IMM32|ole32|OLEAUT32|SETUPAPI|VERSION|WINMM|ntdll|SHLWAPI|MSIMG32|COMDLG32|bcrypt|secur32|api-ms-win|API-MS-WIN)[\s\S]*$'
$result = @{}; $queue = [System.Collections.Generic.Queue[string]]::new()
$queue.Enqueue("$src\build-release\landwar.exe")
while ($queue.Count -gt 0) {
  $f = $queue.Dequeue()
  $deps = & $od -p $f | Select-String "DLL Name" |
          ForEach-Object { $_ -replace '.*DLL Name:\s*','' } | Sort-Object -Unique
  foreach ($d in $deps) {
    if (-not $result.ContainsKey($d) -and $d -notmatch $sysRe) {
      $result[$d] = $true
      $p = Join-Path $bin $d
      if (Test-Path -LiteralPath $p) {
        Copy-Item -LiteralPath $p -Destination "$REL\$d" -Force
        $queue.Enqueue($p)
      } else {
        Write-Warning "Dependency not found in UCRT64 bin: $d"
      }
    }
  }
}
```

本次实际导出得到 31 个第三方 DLL。DLL 数量可能随 MSYS2 版本和链接结果变化，不能只按数量复制，
必须以递归依赖扫描结果为准。

## 5. 拷 data

**需要的运行时资源**：

```powershell
$d = "$src\data"
New-Item -ItemType Directory -Force -Path "$REL\data" | Out-Null

# 配置文件分三类：data/ 下是可编辑主文件，data/default/ 下是发行版回退副本，data/schema/ 下是校验 Schema。
# 任何 default/*.jsonc 都必须在导出时从对应主文件复制，不能手工维护第二份内容。
$configFiles = @(
  "config.jsonc", "render.jsonc", "techs.jsonc", "factions.jsonc", "units.jsonc",
  "city_shapes.jsonc", "city_icon_fits.jsonc"
)
$configDefaultFiles = @(
  "config.jsonc", "render.jsonc", "techs.jsonc", "factions.jsonc", "units.jsonc",
  "city_shapes.jsonc", "city_icon_fits.jsonc"
)
$schemaFiles = @(
  "config.schema.json", "render.schema.json", "techs.schema.json", "factions.schema.json",
  "units.schema.json", "city_shapes.schema.json", "city_icon_fits.schema.json"
)
foreach ($file in $configFiles) {
  Copy-Item -LiteralPath "$d\$file" -Destination "$REL\data\$file" -Force
}

New-Item -ItemType Directory -Force -Path "$REL\data\default" | Out-Null
foreach ($file in $configDefaultFiles) {
  # 关键规范：default 文件直接复制主文件，保证 B 与 A 完全一致。
  Copy-Item -LiteralPath "$d\$file" -Destination "$REL\data\default\$file" -Force
}

New-Item -ItemType Directory -Force -Path "$REL\data\schema" | Out-Null
foreach ($file in $schemaFiles) {
  Copy-Item -LiteralPath "$d\schema\$file" -Destination "$REL\data\schema\$file" -Force
}

$tilingFiles = @(
  "tiling_specs_arch.json", "tiling_specs_laves.json"
)
foreach ($file in $tilingFiles) {
  Copy-Item -LiteralPath "$d\$file" -Destination "$REL\data\$file" -Force
}

# 预装地图。随机地图 gen_*.bmp 不需要随包发布。
$mapFiles = @(
  "map_bigIslands.bmp", "map_desert.bmp", "map_lakes.bmp",
  "map_mainland.bmp", "map_mountains.bmp", "map_twolands.bmp"
)
foreach ($file in $mapFiles) {
  Copy-Item -LiteralPath "$d\$file" -Destination "$REL\data\$file" -Force
}

# 运行时贴图。arrow2.png 是产兵方向箭头，不能遗漏。
$imageFiles = @(
  "army_base.png", "mountain.png", "ring.png", "arrow.png", "arrow2.png"
)
foreach ($file in $imageFiles) {
  Copy-Item -LiteralPath "$d\$file" -Destination "$REL\data\$file" -Force
}

New-Item -ItemType Directory -Force -Path "$REL\data\tower" | Out-Null
Copy-Item -Path "$d\tower\*.png" -Destination "$REL\data\tower" -Force

# 运行期可写目录。程序也会在启动时尝试创建，但发行包中预先建立更直观。
New-Item -ItemType Directory -Force -Path "$REL\userdata\maps" | Out-Null
New-Item -ItemType Directory -Force -Path "$REL\userdata\screenshots" | Out-Null
```

**不需要的**（运行期不加载，剔除以精简）：

- `gen_*.bmp`：随机地图运行缓存，由 `MapGenerator` 按种子确定性重建
- `army.png`（源兵表）、`towers.png`、`city.png`（保留资产，代码不加载）
- `legacy_old_encoding/`、`data\.claude`（均为开发工具/备份）

注意：当前没有 `data/options.json`。选项文件路径是 `userdata/options.json`，由程序首次窗口运行时创建和更新，
所以不能再使用旧版的 `Copy-Item "$d\config.json","$d\options.json"` 命令。

## 6. 写启动器

`$REL\运行游戏.bat`（用 `%~dp0` 定位，可放任意位置，`data/` 按 bat 所在目录解析）：

```bat
@echo off
chcp 65001 >nul
cd /d "%~dp0"
start "" "%~dp0landwar.exe"
```

## 7. 收尾校验（在 $REL 下）

```powershell
$shot = Join-Path $env:TEMP "landwar-release-verify.png"
if (Test-Path -LiteralPath $shot) { Remove-Item -LiteralPath $shot -Force }

& "$REL\landwar.exe" --headless --seed 42 --ticks 100 --summary
$headlessExit = $LASTEXITCODE

& "$REL\landwar.exe" --screenshot $shot --ticks 100 --speed 1000
$screenshotExit = $LASTEXITCODE
$screenshotExists = Test-Path -LiteralPath $shot
$screenshotBytes = if ($screenshotExists) { (Get-Item -LiteralPath $shot).Length } else { 0 }

"headless_exit=$headlessExit screenshot_exit=$screenshotExit screenshot_bytes=$screenshotBytes"
if ($headlessExit -ne 0 -or $screenshotExit -ne 0 -or $screenshotBytes -le 0) { exit 1 }
```

两条程序命令都应返回退出码 0，且截图文件存在且大小大于 0。
本次实际导出目录共约 47MB：Release exe 约 3.9MB、31 个 DLL、data 资源约 0.35MB，
其余空间主要来自 DLL。最终大小会随工具链和资源变化。

本次实际校验结果：

- 发行版 headless：100 tick，退出码 0。
- 发行版窗口截图：退出码 0，PNG 已成功生成。
- 窗口启动时能读取 `data/config.jsonc`、`data/default/*.jsonc`、各配置分片、`data/schema/*.schema.json`、`data/arrow2.png` 和 `data/tower/*.png`。

## 备注

- 一次性交互后再 `start ""` 前无需 `start`，直接运行 `landwar.exe` 亦可（窗口模式会在首启进入主菜单）。
- 用户局把 `userdata/options.json` 会随运行被重写（记录地图与面板设置），发布目录需可写。
- 程序必须从发行版根目录运行，或使用下方启动器；否则相对路径 `data/` 和 `userdata/` 可能解析错误。
