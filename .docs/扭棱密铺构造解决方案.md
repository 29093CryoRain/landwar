## 2. 问题分析

### 2.1 为什么单标签边传播对扭棱类失效

边传播假设“每个面型对应一个规范环序标签”。对 3.3.3.3.6 来说，
三角形在真实密铺中必须扮演两种角色：

- **贴边三角形**：与一个六边形共享边，另外两条边邻三角形，标签 `[3,3,6]`。
- **纯缝三角形**：三条边都邻三角形，标签 `[3,3,3]`。

两者数量比 6:2（每 8 个三角形中有 6 个贴边、2 个纯缝），必须按几何位置同时出现；
单取任一种标签都会导致退化或冲突。

对 3.3.4.3.4，本构造进一步表明：真实密铺中所有三角形的标签都是 `[3,4,4]`
（两边邻正方形、一边邻三角形），`[4,4,4]` 只是组合枚举给出的伪标签，不能闭合成
3.3.4.3.4。单序列边传播失败的本质不是“缺第二种标签”，而是三角形边标签的
**定向放置必须服从正方形取向的交替（棋盘格手性）**，而单序列传播无法表达这种
“同一序列在不同局部上下文中的定向不同”。

### 2.2 解决思路

改为 **“大面中心格点 + 顶点扇形局部规则”**：

1. 扭棱类密铺中，非三角形面（六边形/正方形）互不接边，且其中心形成一个平面格点
   （六边形 → 三角格点；正方形 → 方格点，带两种取向的棋盘格）。
2. 每个顶点处，正多边形内角扇形唯一决定了该顶点周围所有面的几何位置。
3. 因此只要确定“大面”的格点与取向，所有三角形都可以由大面的边向外长出来；
   纯缝三角形由同一大面相邻两条边上的贴边三角形之间的空隙确定。

这样得到的构造是**确定性、闭合、可周期化**的。

## 3. 构造算法（共用的周期域折叠）

输入：面集合（多边形顶点，CCW）+ 该密铺的平移格基 `(Wlat, Hlat)`。
输出：矩形周期 `W=(wx,0)`、`H=(0,hy)` 与基础面表。

1. 若 `det(Wlat, Hlat) < 0`，交换二者，保证正向。
2. 整体旋转 `-arg(Wlat)`，使 `Wlat` 水平，得到 `W=(wx,0)`、`H=(hx,hy)`。
3. 求最小垂直周期：`m = denominator(Fraction(hx/wx).limit_denominator(8))`；
   取 `H_rect = (0, hy*m)`。本文两种 Arch 的 `hx/wx` 分别为 1/2（33336）和 0（33434），
   因此矩形周期分别为 `(√7 L, 0)×(0, √21 L)` 和 `(√6, 0)×(0, √6)`。
4. 对每个面的形心 `c`，计算
   `u = frac(c.x / wx)`，`v = frac(c.y / hy_rect)`（`frac` 用 `x - floor(x)`）。
   只对 `|u|<ε` 或 `|u-1|<ε` 做 0/1 数值吸附；**禁止把 0.98 以上统一吸附为 0**，
   否则会把形心略在域外（负侧）的面错放到域左边界（本文 laves_33434 曾因此边不配对）。
5. 按 `(u,v)` 去重，每个代表面平移到 `(u*wx, v*hy_rect)` 作为基础格中心，
   顶点同步平移，得到基础面绝对坐标。基础面允许部分顶点越出矩形域，这是正常
   的周期域表示（C++ 引擎按周期平移找邻接）。

## 4. Arch 3.3.3.3.6 构造（六边形三角格点）

以下先令 `L=1`，最后整体乘 L。记 `ω = e^{iπ/3}`（60° 旋转）。

### 4.1 格点与手性

取六边形中心格点为三角格：

```
C_{m,n} = C0 + m W + n V,
C0 = e^{i60°},
W  = (-1/2, -3√3/2),
V  = Rot_{60°}(W) = (2, -√3)。
```

这是本方案选择的**左手性**；镜像手性取 `V = Rot_{-60°}(W)`（或对所有坐标取共轭）。

### 4.2 大面与三角形

对每个格点 `C`：

1. 六边形顶点（CCW）：
   `hv_k = C + e^{i(60° k - 120°)}`，`k=0..5`。
2. 对每条边 `hv_k -> hv_{k+1}`，向外长贴边三角形：
   `w_k = hv_k + (hv_{k+1}-hv_k) * e^{-i60°}`；
   三角形 `(hv_k, hv_{k+1}, w_k)`，其六边形邻边是 `hv_k-hv_{k+1}`，标签 `[3,3,6]`。
3. 对每个顶点 `hv_k`，取上一条边上的贴边三角形外顶点 `w_{k-1}`，在边
   `hv_k - w_{k-1}` 的另一侧长纯缝三角形：
   ```
   p_k = hv_k + (w_{k-1} - hv_k) * e^{±i60°}   // 取不等于 hv_{k-1} 的那个
   ```
   三角形 `(hv_k, w_{k-1}, p_k)`，标签 `[3,3,3]`。

### 4.3 去重与数量

- 六边形、贴边三角形：每个格点独立生成，各 1 个/格点、6 个/格点。
- 纯缝三角形：每个六边形顶点生成一次，但每个纯缝三角形被 3 个六边形共享，
  去重后每格点 2 个。

因此原始格 `(W,V)` 内含 1 六边形 + 8 三角形（6 贴边 + 2 纯缝），数量比 8:1。

### 4.4 矩形周期

`det(W,V) = 7√3/2`。旋转使 `W` 水平后：
`W' = (√7, 0)`，`V' = (√7/2, √21/2)`。
`hx/wx = 1/2`，故矩形域取
`W_rect = (√7 L, 0)`，`H_rect = (0, √21 L)`，含 2 个六边形和 16 个三角形（共 18 面）。

## 5. Arch 3.3.4.3.4 构造（正方形棋盘格点）

以下仍先令 `L=1`，最后整体乘 L。

### 5.1 格点、取向与手性

取正方形中心格点：

```
U = ((3+√3)/4, -(1+√3)/4)
V = i U = ((1+√3)/4, (3+√3)/4)     // 左手性；镜像取 V = -i U
C_{m,n} = C0 + m U + n V
C0 = (-(1+√3)/4, (√3-1)/4)
```

正方形**取向棋盘格交替**：

```
θ(m,n) = -15°  当 m+n 为偶数
θ(m,n) = +45°  当 m+n 为奇数
```

正方形顶点（CCW）：
`q_k = C + (1/√2) * e^{i(θ + 90° k)}`，`k=0..3`。

> 注意：这不是一个“单一方格点”的均匀格；`U` 平移会把偶数取向翻成奇数取向，
> 因此 `U` 不是平移对称。真正的平移格基是 `A=U+V`、`B=U-V`（二者等长且正交），
> 其原胞含 2 个正方形。

### 5.2 三角形

对每个正方形的每条边 `q_k -> q_{k+1}`，向外长三角形：
`w_k = q_k + (q_{k+1}-q_k) * e^{-i60°}`；
三角形 `(q_k, q_{k+1}, w_k)`。

该三角形同时与另一个（取向相反的）正方形共边，因此每个三角形由两个正方形各生成
一次，去重后每 2 个正方形配 4 个三角形。每个三角形有两条边邻正方形、一条边邻
三角形，即唯一标签 `[3,4,4]`。

### 5.3 矩形周期

`A=U+V = ((2+√3)/2, 1/2)`，`B=U-V = (1/2, -(2+√3)/2)`，`|A|=|B|=√(2+√3)`，
且 `A ⊥ B`。旋转使 `A` 水平后得到正方形周期：
`W_rect = H_rect = √(2+√3) L`。
按平均 Arch 面面积=1 取 `L=√(6/(2+√3))` 时，`W_rect=H_rect=√6`。
矩形域含 2 个正方形 + 4 个三角形（共 6 面）。

## 6. Laves 对偶生成

1. 用第 4/5 节算法生成足够大的 Arch 面片（格点范围取 `-7..7` 或 `-8..8` 即可覆盖
   矩形周期及边界外一圈）。
2. 对每个 Arch 顶点，收集环绕它的所有面（应为 5 个）。按这些面的中心相对该顶点的
   极角排序，得到 Laves 五边形（CCW）。
3. 五边形按顶点集去重。
4. 计算原始五边形面积 `A0`，整体缩放 `s = 1/√A0`，使每个 Laves 面面积 = 1。
5. 用第 3 节折叠算法，把缩放后的五边形折叠到缩放后的平移格 `s*Wlat, s*Hlat` 中。

两种 Laves 面的边长模式（面积归一化后）：

| Laves | 边序列 | a | b |
| :--- | :--- | :--- | :--- |
| laves_33336 | a,a,a,b,b（b=2a） | 0.574381789002 | 1.148763578004 |
| laves_33434 | a,b,b,b,b | 0.597716981445 | 0.816496580928 |

## 7. 验证结果

对附录 JSON 做了以下检查，全部通过：

1. **边配对闭合**：每个基础面的每条有向边，都能在 `dr,dc ∈ [-2,2]` 的周期平移内
   找到反方向重合边（C++ 引擎邻接搜索范围）。
2. **顶点构型**：
   - arch_33336 所有满价顶点 = 4 个三角形 + 1 个六边形。
   - arch_33434 所有满价顶点 = 3 个三角形 + 2 个正方形。
   - laves_33336 顶点度为 3（三角中心）或 6（六边中心）。
   - laves_33434 顶点度为 3（三角中心）或 4（正方中心）。
3. **数量比**：
   - arch_33336 三角:六边 = 16:2 = 8:1。
   - arch_33434 三角:正方 = 4:2 = 2:1。
4. **面积**：arch 平均面面积 = 1（矩形域面积 = 基础面总面积）；laves 每个面面积 = 1。
5. **Laves 全等性**：所有 Laves 基础面面积一致、边长模式一致。
6. **确定性**：所有构造只依赖密铺类型与手性符号，无随机过程。

## 8. 手性与镜像

本文 JSON 选择的是**左手性**（chirality sign = +1）：

- arch_33336：`V = Rot_{+60°}(W)`。
- arch_33434：`V = +i U`。

需要镜像版本时，对全部坐标取共轭（`y -> -y`），或将上述 `V` 改为
`Rot_{-60°}(W)` / `-i U` 后重新折叠。两者互不平移，且产生的是同一组数量比与
Laves 全等性，只是朝向相反。
