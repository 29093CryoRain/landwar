
# 异种地图细节:
一期:
先做六边形密铺和三角形密铺
根据格的面积大小一致来推导边长.
六边形和三角形密铺每个单元的正六边形/正三角形, 存在顶点在正上下方, 而非正左右方.
注意到三角形密铺存在正向和反向的三角形, 小心处理.
六边形密铺时允许出现的城市等级,及其对应的基建地块的形状:{
    1:一个六边形格
    3:上, 左下, 右下三个六边形格
    4:在3级城的基建地块的基础上,下方再添置一个六边形格
    6:在4级城的基建地块的基础上, 最下面那一格的左右两侧各添加一个六边形格. 整体六个六边形格排成近似三角形.
    7:一个六边形格及其所有邻格.
    9:在7级城的基础上, 最上方和最下方再添一个六边形格, 形似菱形.
}
三角形密铺时允许出现的城市等级,及其对应的基建地块的形状:{
    1: 一个三角形格(正, 反三角形都可以)
    2: 一正一反两个三角形(连通, 有公共边)
    4: 边长2倍于单个三角形地块的大三角形所包含的四个小三角形.(正反都可以)
    6: 六个三角形围起来的正六边形形状.(这个正六边形是正左右方存在顶点, 正上下方不存在顶点)
    8: 在6级城的基础上, 最上方添加一个正三角形, 最下方一个反三角形. 也可以视为一正一反两个四级城拼接. 也可视为边长2倍于2级城的形状.
}
这些基建地块连成的形状都较为匀称, 请使用些许计算来确定城市贴图的缩放倍率, 贴图边缘在离基建地块最边缘有恰好一点点距离最好, 具体倍率数值填入config.json中(现在已有正方形网格的数据, 你可以用正方形网格环境及其数值来测试计算算法的正确性).
开拓兵特性延拓: 与目标地块有公共边的相邻地块会被其一次性征服.
边界:
为适配环绕地图(地图上下,左右侧视为连通的), 三角形地图时, 最上下侧应是平的(即最上侧有一层反三角形, 最下侧有一层正三角形), 左右侧应是互补的(左边若凹,右边就凸)
六边形地图时, 应保证有偶数行. 另外, 使用一圈灰线描出整个地图的边界.
前面提到了格大小不变, 那么对于山的渲染, 在六边形和三角形密铺下, 大小不用动.
主菜单点进随机生成地图时, 应出现选择密铺模式的下拉菜单.
---
二期:
半正密铺:
规范:{
    地图长/宽可自行定义具体含义, 可以规定这两个数值需满足的性质(例如必为偶数, 需适配-与+按钮), 但需保证长*宽=总格数(实在不行的话向用户说明).
    需保证所有网格的平均面积与正方形密铺的一样, 具体数值见下方.
    为适配环绕地图, 需保证边界是契合的, 从一侧到另一侧可以恰好匹配.
    需保证有限的实际的地图上的几种多边形的数量比与密铺(无限的情况)的数量比一致, 尽管这可能破坏整张地图的对称性.
    当开启强制边缘为海, 且陆地面积100%时, 处理为仅最靠近地图边缘的那些块是海, 且所有海块均边相连, 连通成一体.
    开拓兵特性延拓: 与目标地块有公共边的相邻地块会被其一次性征服.
    山地贴图缩放比例应为所在格面积的平方根, 也即这个贴图面积是和所在格面积成正比的.
}
下面这部分文档中"方向规范"的说明:
对于这些密铺, 存在一种角度, 旋转后能满足方向规范中的要求.
下面这部分文档中"可能出现的城市"格式规范:
前面的数字表征应该使用的贴图是几级城市, 具体的城市等级根据包含的图形面积之和计算(实数), 城市等级四舍五入后应当就是贴图对应的城市等级, 除了3.12.12中的4级, 这是为了与3级区分开. 其他的如果有出入, 则可能是用户计算失误, 以实际为准.
所有提及的城市基建地块的形状都是尽可能地"圆"的, 如果你对语句感到歧义, 选择最圆最对称的.

### 1. 顶点构型 3.3.3.3.6  
（数量比 三角形 : 六边形 = 8 : 1）

- **缩放边长**：  
  \[
  L = \sqrt{\frac{9}{14S_3}} = \sqrt{\frac{18}{7\sqrt{3}}} \approx 1.2184
  \]
- **单个面积**：
  | 多边形 | 面积（精确） | 面积（数值） |
  | :--- | :--- | :--- |
  | 正三角形 | \( \frac{9}{14} \) | 0.6429 |
  | 正六边形 | \( \frac{27}{7} \) | 3.8571 |
- **方向规范**:
  三角形可能正上/下方有顶点, 左右方无顶点. 六边形仅正左右方有顶点.
- **可能出现的城市**:{
    1: 一正一反两个三角形组合而成的, 两三角形公共边是水平方向.
    3: 四个小三角形组成的大三角形, 可能正也可能反.
    4: 一个正六边形.
    5: 一个正六边形加上其正上方与正下方两个三角形.
    9: 一个正六边形加上其左右两侧, 每侧各4个三角形(六边形最左侧顶点同时是左侧的四个三角形的顶点, 右侧同理), 总计8个三角形1个六边形, 整个图形左右轴对称, 上下轴对称.
}

### 3. 顶点构型 3.3.4.3.4  
（数量比 三角形 : 正方形 = 2 : 1）

- **缩放边长**：同第 2 种，\( L \approx 1.2679 \)
- **单个面积**：同第 2 种（三角形 ≈ 0.6962，正方形 ≈ 1.6077）
- **方向规范**:
    三角形之间的公共边是水平或竖直的, 其余边均不水平不竖直
- **可能出现的城市**:{
    1: 一个三角形(仅允许上下三角形)
    2: 一个正方形
    5: 一个顶点附近的5个图形, 但需保证整体是左右对称的, 上下不对称. 这包含一正一反两种可能.
    12: 找到两个有公共边的三角形, 两个三角形及所有与其有公共顶点的格子,共计8个三角形,4个正方形 有两种可能, 互相呈转了90度的关系, 且两者都左右对称上下对称.
}

Laves密铺:
各种规范同半正密铺的, 除了城市: 下面这部分文档的"可能出现的城市"中,前面的数字就是城市等级(正整数), 也是地块数量. 每个方向规范/可能出现的城市是修饰上文最近的那个密铺的.
显然, 在上述规范下,laves密铺每个格子的面积为1.
补充规范:
1. Laves密铺存在同级不同形状的城市: 使用同种城市贴图; 该级贴图缩放取各同级形状各自"不超出基建地块且尽可能大"的允许缩放中的最小值, 以保证任意同级形状都不出边界(允许平移).
2. 10级及以上等级的城市统一使用一种贴图(新贴图开发途中准备好, 未就绪时先用9级城的贴图).
3. 本阶段共14种地图形式, 建议横向开发(不整做完一个密铺再做下一个); 先完整统计需要修改的代码位置列成表.
4. 视觉相关问题统一由用户测试, 不要自行调用视觉功能; 尽量复用六边形/三角形密铺的代码.
5. 先开发几何小工具: 任意密铺情形下, 给定城市基建地块及城市贴图大小, 计算缩放比例使城市贴图不超出基建地块范围且尽可能大(允许平移).
---

对于 8 种 Laves 密铺（即 8 种半正阿基米德密铺的对偶，不包括正三角形、正方形、正六边形对应的三种正密铺），若要求每个全等的凸多边形面面积均为 **1**，各边长如下。

推导时，先取对应阿基米德密铺原边长为 1，则 Laves 密铺的边长为相邻正 \(n\) 边形内切圆半径之和  
\[
r_n=\frac{1}{2\tan(\pi/n)}.
\]
再乘以缩放因子 \(s=1/\sqrt{A_0}\)（\(A_0\) 为原面积）即可。

### 1. 对偶于 **3.6.3.6** —— 菱形
所有边相等：
\[
\boxed{a=\frac{\sqrt{2}}{\sqrt[4]{3}}}
\]

方向规范:
部分菱形长对角线是水平的, 短对角线是竖直的.
可能出现的城市:{
    1: 一个长对角线是水平的, 短对角线是竖直的菱形.
    3: 一个顶点附近的全部三个菱形组成的六边形. 有两种可能, 但组成的六边形都是一样的形状, 只是内部的菱形排列不一样.
    5: 一个长对角线是水平的, 短对角线是竖直的菱形及与其有公共边的四个菱形.
    6: 一个顶点附近的全部六个菱形组成的雪花状图形.
    12: 在6级城的基础上, 加入所有与其有邻边的菱形, 组成一个大的正六边形.
}

### 2. 对偶于 **3.12.12** —— 等腰三角形
两腰相等，底边不同：
\[
\boxed{a=\frac{2}{\sqrt[4]{3}},\quad b=2\sqrt[4]{3}}
\]
（顺序：\(a,a,b\)）
方向规范:这个实际上就是 对偶于 3.6.3.6 —— 菱形 密铺方式将所有菱形沿着长对角线分成2个等腰三角形的密铺, 方向规定也与上面的一样.
可能的城市:{
    2: 两个等腰三角形底边为公共边组成的菱形, 也像是 对偶于 3.6.3.6 —— 菱形 密铺中的1级城
    3: 三个三角形顶角所在的点为三者的公共点组成的等边三角形. 正反两种情况.
    6: 像是 对偶于 3.6.3.6 —— 菱形 密铺中的3级城, 是个大的六边形. 正反两种情况.
    6: 两个3级城, 一正一反两个大三角组成的菱形. 两个大三角的公共边应为水平方向的.
    12:像是 对偶于 3.6.3.6 —— 菱形 密铺中的6级城, 是个大的雪花.
}
---

### 3. 对偶于 **4.6.12** —— 不等边三角形
三边分别为：
\[
\boxed{
x=\frac{\sqrt{2}}{\sqrt[4]{3}},\quad
y=\frac{2\sqrt{2}}{\sqrt[4]{3}},\quad
z=\frac{3+\sqrt{3}}{\sqrt{3+2\sqrt{3}}}
}
\]
方向规范:{
    存在竖直方向的斜边, 不存在水平方向的斜边.
    或者说, 这种密铺实际上是上一种密铺 对偶于 3.12.12 —— 等腰三角形 进行处理得到的, 将所有等腰三角形沿着从顶角出发的角平分线, 分割为两个直角三角形, 就得到了此种密铺.
}
可能的城市:{
    2: 两个三角形斜边为公共边, 但斜边需为竖直方向, 组成筝形.
    4: 2级城的基础上, 加入与 两个三角形的长直角边 相邻的另外两个三角形, 共计四个三角形, 组成菱形. 与3.12.12 —— 等腰三角形 的2级城类似.
    4: 四个三角形的直角顶点共顶点,组成的菱形. 和上文的4级城组成的菱形实际一致, 只是内部三角形排列不一样.
    6: 6个三角形的长直角边的对角所在的顶点共顶点, 组成大等边三角形. 也是3.12.12 —— 等腰三角形 的3级城类似.
