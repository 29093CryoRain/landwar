主循环事件流（`Application::run`）：
```
input_.beginFrame();          // 重置帧内累积动作
processEvents();              // 逐事件：ui::processImGuiEvent + input_.handleEvent + SDL_QUIT
applyInputs();                // 相机/倍速/暂停/点选/截图/重载
if (!paused_) sim.tick() ×N;  // 固定步长（speed_ 累加）
renderFrame();                // 清黑 → 地图 → 兵 → 特效 → ImGui 面板 → Present
```

## 2. 坐标空间（核心事实，务必牢记）

渲染使用 `SDL_RenderSetLogicalSize(ren_, 2175, 1425)`：**所有渲染发生在逻辑坐标空间**，
窗口缩放只是 SDL 对最终帧的显示变换。坐标系存在三种"坐标"：

| 坐标 | 来源 | 用途 |
|---|---|---|
| **窗口像素** | `SDL_GetMouseState` / `SDL_GetGlobalMouseState` | 滚轮缩放锚点（需换算） |
| **逻辑坐标** | **SDL 鼠标事件**（motion/button 的 x/y 与 xrel/yrel） | 相机/点选/ImGui 面板直接使用 |
| 世界坐标 | `camera_.toWorldX/Y` | 格点/兵的逻辑坐标 |

**关键事实（实测确认）**：当窗口关联了带逻辑尺寸的渲染器时，SDL **自动把鼠标事件的
坐标换算为逻辑坐标**（push 窗口像素 (100,100) → 事件收到 (148,148)）。而
`SDL_GetMouseState` 系列返回**窗口像素**。

因此：
- **InputManager 的 `actions_.mouseX/Y`、`panDX/DY` 都是逻辑坐标**，`Application` 直接使用，
  **不得再调 `SDL_RenderWindowToLogical`**（否则双重放大 ≈×2.2，点选/UI 全偏）。
- **滚轮缩放锚点例外**：滚轮事件不携带位置，须用 `SDL_GetMouseState`（窗口像素）+
  `SDL_RenderWindowToLogical` 换算后再做锚点。
- 逻辑尺寸 + 窗口纵横比不一致时，SDL 用 **letterbox 视口**（逻辑坐标，含居中偏移）缩放，
  `SDL_RenderWindowToLogical` 已正确处理偏移。

## 3. 两处 imgui 后端补丁（升级 imgui 必须重新套用）

### 3.1 `imgui_impl_sdl2.cpp`
1. **NewFrame**：把 `io.DisplaySize` 覆盖为逻辑尺寸、`io.DisplayFramebufferScale=(1,1)`。
   原因：默认用窗口像素作 DisplaySize，而渲染在逻辑空间 → UI 按窗口像素布局却渲染到
   逻辑空间，碰撞与渲染错位。
2. **SDL_MOUSEMOTION 事件**：坐标已是逻辑，**直接用**（不得再换算）。
3. **UpdateMouseData 兜底**：用 `SDL_GetGlobalMouseState - SDL_GetWindowPosition`（=窗口像素）
   经 `ImGui_ImplSDL2_ApplyLogicalSize` 换算为逻辑。
   > 曾试"在 `ImGui::NewFrame` 前外部改 `io.MousePos`"，无效：NewFrame 的 `UpdateInputEvents`
   > 会把输入队列里的原始坐标写回覆盖。

### 3.2 `imgui_impl_sdlrenderer2.cpp`
- `SetupRenderState` **不再重置视口**（删掉 `SDL_RenderSetViewport(renderer, nullptr)`）。
  原因：letterbox 窗口下 SDL 默认视口 = 逻辑内容区（含居中偏移）；重置为 nullptr 会把
  视口变成逻辑空间全窗口（比画布宽），ImGui 几何丢到 letterbox 偏移处渲染 →
  渲染位置与命中区错位 → 最大化/改窗口大小后"点击要偏右"。

## 4. 中文字体

ImGui 默认字体（ProggyClean）无 CJK 字形，中文显示为 `?`。`ImGuiSetup::initImGui`
从系统字体候选加载默认字体（微软雅黑 `msyh.ttc` / 黑体 / 宋体 / 等线，取首个成功者），
`GetGlyphRangesChineseFull()` 覆盖常用汉字。失败则回退默认并记警告（中文变 `?`）。
字体在首次 NewFrame 时由 SDLRenderer2 后端构建图集纹理。

## 5. 点选逻辑（`Application::pickSelection`）

**兵（屏幕空间点选，与渲染视觉对齐）**：
- 锚点 = sprite **绘制中心** `(camera_.toScreenXi(x), camera_.toScreenYi(y))`。
  （渲染曾加 `spriteSize/2`（16px）的 y 偏移，后取消；**点选与渲染必须一致**——两边都不加偏移。）
- 半径 = 该兵种 `config.units[].visualRadius × zoom`（**按兵种外置表**，非统一半格）。
- 判定：取 `ratio = 距离 / 半径` 最小者，且 `<1` 才命中（选"光标相对其视觉最居中"的兵）。

**格（世界坐标，精确）**：`camera_.toWorldX/Y(点击逻辑坐标)` → `floor` 取格。

**visualRadius 校准**：量法工具见 `tools/measure_visual_radius.cpp`（最远像素距离 × 绘制
缩放 48/32）。最远值偏大，最终以**用户目测校准**为准：
普通 12 / 先锋 13 / 开拓 15 / 激光 20 / 爆炸 21 / 地雷 17（存于 `data/config.json`）。
更换 army.png 后重跑工具参考 + 目测微调写回。

## 5.5 玩家模式交互（P2）

> 菜单里把某势力 AI 设为「玩家」后生效（`Faction.aiId==1`；读档后也正确，aiId 随快照）。

**进入游戏**：`Application::initPlayerIntent()` — 初始 `selectedType=普通兵`、
`cityX/Y=初始城市（首都 cities[0]）`，并**进入暂停**（玩家先看局势再操作）。

**兵种选择**：数字键 `1-6` 或面板图标栏（`ImGui::ImageButton`，army.png 子图）选兵种；
图标栏最左为**空框 = 不生产**（`selectedType=-1`），`` ` `` 键等价（2026-08-03）。
图标下方成本 = `faction.armyCost`（已含势力 `costDiv` 折扣）。玩家操控时 `1-4` 不再调速
（倍速走 `+/-` 与面板）；非玩家模式 `1-4` 调速。

**城市选择**（`Application::updatePlayerIntent`，每帧执行）：
- **判定（屏幕空间，参考 §5 兵点选）**：鼠标到己方城市中心的**屏幕距离** ≤
  `max(20px, config.player.hoverCityRadius × cellPx)` → 命中最近者。随缩放等比、下限 20px
  （缩小时不缩到难以选中）。**范围内有可选城市即命中**（无需鼠标移动，每帧重算）。
- **闪烁根因与修复**：`InputManager::beginFrame` 曾把 `actions_` 整体清零 → 无 motion 事件的帧
  `mouseX/Y=0,0` → 悬停目标按左上角重算 → 指示随"有无 motion 事件"闪。修复：beginFrame 保留
  最近一次鼠标位置（`actions_.mouseX/Y` 不清零）。
- **悬停/待选指示**：四箭头（`render/CityMarkerRenderer::makeArrowTexture`，不旋转）指向
  "按下鼠标会选中的城市"。
- **产兵城指示**：旋转虚线环（`makeRingTexture`，旋转角 = `sim.tickCount()×markerRotateSpeed`，
  **不动 sim RNG**）。左键点击命中城市 → 选为产兵城。
- 两类指示颜色都按**城市显示亮度** `mix_color(势力色, 黑, 0.8)`（MapRenderer 城市格同款，
  用户反馈原标记太亮）。

## 5.6 面板系统（P3）

> 多面板框架（思路 6.0）：除主面板外的面板可隐藏、移动位置；主面板"面板"区列出各面板开关，
> 每个可见面板标题栏有"隐藏"按钮。纯 UI 改动，不影响模拟/基线。

- **主面板**：`DebugPanel`（固定左侧、不可移动/隐藏，`state.mainPanel=true`），标题区新增
  **"面板"分组**——每个注册的可移动面板一个 checkbox（勾选=显示）。隐藏的面板从这里重新打开。
- **可移动面板**（`PanelManager::draw`）：统一可拖动窗口（`ImGuiWindowFlags_NoTitleBar` →
  整窗可拖）、自绘标题栏（标题 + 右上角**"隐藏"按钮`）、位置/大小随帧回写 `state.x/y/w/h`。
  默认位置 = 主面板右侧、默认大小随 `uiScale`（长条选项区长度随缩放——用户增注 5）。
- **布局持久化**：可移动面板 `id/visible/pos/size` 存 `userdata/options.json`（2026-08 起）的
  `panels` 段；
  `Application::setupPanels()`（init 时）恢复布局，`run()` 退出时 `syncPanelLayout()`
  + `saveToFile` 写回 → 重启读回位置/可见性（主面板不入持久化，恒显示）。
- **ImGui 捕获**：`WantCaptureMouse` 抑制游戏输入（沿用 §7 逻辑），拖动/隐藏不误触游戏操作。
- **当前面板**：主面板 + "消息"面板（P4）。

## 5.7 消息系统（P4）

> 重大事件（思路 6.0.5：势力灭亡/统一/科技取得）在独立消息面板弹出，留存后渐隐、超量丢最旧。
> 纯展示通道：事件**不进快照**、不消耗 RNG → 不影响模拟确定性。

- **事件产生**（`Simulation` 纯逻辑）：`detectAnnihilationAndUnification()` 在 tick 末尾
  （特效/死亡结算后）调用——`alive && cityCount==0 && countArmies==0 && countEffects==0`
  → 发 `FactionAnnihilated` 并置 `alive=false`（残留地雷/激光/爆炸不误报）；alive 势力==1 →
  恰一次 `Unification`。文案含势力名（`factionShortName`，`core/GameDefs.h` 共享）。
- **drain**：`Application::renderFrame` 每帧 `drainEvents()` → `sim.takeEvents()` →
  `MessagePanel::addEvents`（**有消息自动弹出面板**）。
- **文案**：事件文本带时间前缀 `(Xs)`（tick→秒，`config.sim.tickRate` 换算；主面板顶部
  `时间:` 同源显示 tick 计数，P4 修正去掉 debug 风格变量名）。
- **渲染**：`MessagePanel::draw` 读 `MessageLog`——消息**持续留存不自动消失**，仅超
  `messageMaxShown` 丢最旧；`renderMessageText` 按势力名切三段渲染（前缀白 + 势力名按势力色
  + 后缀白；`factionId=0` 或文本无该名 → 整段白）。
- **清理**：F5 重载配置时 `MessagePanel::clear()` 清空旧局消息。

## 6. 键位与操作

| 输入 | 行为 | 实现 |
|---|---|---|
| 空格 | 暂停/继续 | `InputActions.togglePause` |
| ESC 双击（500ms 内） | 暂停/继续 | 非阻塞状态机（单击不动作） |
| `1/2/3/4` | 1x/2x/4x/8x 倍速（**玩家操控时 1-6 选兵种**，倍速走 `+/-` 与面板） | `speedSelect` |
| `1`–`6` | **玩家模式**：选兵种（普通/先锋/开拓/激光/爆炸/地雷） | `selectUnitType` |
| `` ` `` | **玩家模式**：不生产（`selectedType=-1`，与图标栏最左空框等价，2026-08-03） | `selectNone` |
| `+`/`=`、`-` | 倍速档位循环步进（0.25x~8x） | `speedCycle` → `cycleSpeed` |
| `F6` | **步进一帧**：跑一个逻辑帧后进入暂停，再按再跑（测试用） | `stepFrame` → `stepPending_` |
| 滚轮 | 缩放（锚定光标） | `wheelDelta` + SDL_GetMouseState 换算锚点 |
| 右键拖拽（>6px） | **平移**（2026-08-03：拖动屏幕改右键） | `dragActive` + `panDX/DY`（逻辑坐标） |
| 左键单击 | 点选兵/格/己方城市 | `click` → `pickSelection` / `updatePlayerIntent` |
| `F5` | 重载配置（**重建模拟，同种子重启**，破坏当前局面） | `reloadConfig` |
| `F12` | 截图 `userdata/screenshots/screenshot_N.png`（2026-08 起） | `takeScreenshot` |
| 窗口关闭 | 退出 | `SDL_QUIT`（ESC 单击不退出） |

**倍速档位（`cycleSpeed` 的 kSteps）**：`{0.25, 0.5, 1, 2, 4, 8}`。含 <1x（0.25/0.5）用于
测试——固定步长累加器天然支持（`accumulator += frame*speed_`，低速时逻辑帧自然隔帧执行，
**无需拆分逻辑帧**）。`1/2/3/4` 键直接设 1/2/4/8x；`+`/`-` 与面板按钮在全部 6 档间循环。

**步进（`stepPending_`）**：`run()` 里优先于正常累加——`if (stepPending_) { sim_.tick();
stepPending_=false; paused_=true; accumulator=0; }`，保证恰好推进一个逻辑帧（含死亡/特效
结算，`sim_.tick()` 内部完成）后进入暂停。F6 键在 `applyInputs` 置位（本帧即执行），面板
"步进 (F6)" 按钮经 `UiRequests.stepFrame` 置位（下一循环迭代执行）。

**交互与模拟解耦**：除 F5 重载（重建模拟）外，交互只改渲染节奏/相机/UI，**绝不触碰
sim RNG 或状态** → 确定性/回放成立。鼠标落在 ImGui 面板上时（`io.WantCaptureMouse`），
游戏拖拽/点选/滚轮被抑制（`InputManager::setMouseCaptured`）。

## 7. 维护注意点（易错陷阱）

1. **不要双重换算坐标**：事件坐标已是逻辑；`SDL_GetMouseState` 才是窗口像素。搞混 → UI/点选偏移。
2. **渲染与点选锚点必须一致**：曾加 `spriteSize/2`(16px) 的兵 sprite y 偏移，后取消
   （渲染与点选都**不加偏移**）。改任一处的锚点（位置/缩放）都要同步另一处。
3. **`visualRadius` 在 `data/config.json`**（数据驱动），改兵种视觉 → 改表 + 重建。
4. **升级 imgui 后必须重新套用 §3 的两处补丁**（文件头有注释说明）。
5. 新增 UI 时面板宽度按 `kBasePanelWidth × uiScale` 缩放（`kBasePanelWidth=312`，Phase 9 由 520 瘦身 ×0.6）；`uiScale` 经 `io.FontGlobalScale` 生效。
6. `InputManager` 单测用合成 SDL_Event，**无渲染器时坐标不经过 SDL 转换**（原始值）——
   测试语义与真实运行不同属预期。
7. **步进 = 一个逻辑帧（`sim_.tick()`）**，与渲染帧无关；步进后必进入暂停。`0.25x/0.5x`
   靠累加器自然隔帧执行逻辑帧，**不要为低速拆分逻辑帧**。
8. **统一 tint 管线**（`render/TintCache` + `TintMath`）：读入源图 → 按势力色烘焙多版本
   存内存，两种模式：
   - **Multiply**（`tintPixel`）：白/灰源 → 目标色（玩家标记 `data/ring.png`/`arrow.png`、
     P5 山地/城市线条贴图 `data/mountain.png`/`city.png` 用——`MapRenderer::bake` 烘焙 9 版本，
     下标即势力 id 含中立 0）。
   - **HueRotate**（`hueRotatePixel`）：彩色源**按色相旋转**到目标色——军队精灵用。原图各势力
     列是纯色相旋转（max/min 通道恒定），**灰度 luma 会压暗并破坏跨列亮度一致**，必须用 hue
     旋转才精确复现；白色像素（s=0）自动不动 → 激光白芯天然保留。
   数据：`data/army_base.png`（源列0 红，HueRotate）+ `data/army_special.png`（签名兵种特殊版
   原样彩色，青先锋/蓝开拓/绿激光/橙爆炸/紫地雷）；`kSpecialUnitFaction`（`core/GameDefs.h`）
   决定谁用特殊版。P5 山/城 tint 目标色：山=8% 势力色（近黑）、城=85%（略深），
   `mixColor(色,黑,rate)` 的 rate=**势力色占比**（计划草案给的山 0.92/城 0.15 与其文字描述相抵触，
   按描述实现）。**陷阱**：① tint 在启动时从 config 势力色烘焙，F5 重载会重烘焙
   （`reloadConfig`）——不要在别处缓存势力色纹理；② 改了源图必须重跑对应 `tools/gen_*.py`
   再烘焙；③ `SpriteSheet::texture(factionIndex)`（势力色基础版）与 `specialTexture()`（特殊版）
   是**不同纹理**，`rect(type)` 单列索引——别混成旧的 `rect(type, factionIndex)`。
