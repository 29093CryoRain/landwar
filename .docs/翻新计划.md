# 游戏行为规格（landwar）

> 本文件是从代码提炼的游戏行为规格，**修改行为前必读**。所有数值以 `data/config.json`
> 为准（键义见 `.docs/配置说明.md`）；工程纪律见 `.docs/工程规范.md`；交互/输入事实见
> `.docs/交互系统.md`。「帧」统一定义为**逻辑 tick**（60Hz）。
>
> 相对原版 DxLib 版的行为改动集中记录在 §11，新增改动时须同步追加。

---

## 1. 地图与初始化

- 网格 105×95；`mmap[i][j]`：`{x, y, land, city, belongi}`。
- `map.bmp` 地形基图语义：**RGB 概率权重**——任一分量 <32 = 海；山概率 = ramp(R)、
  城概率 = ramp(G)、B 闲置；每陆格掷骰两次。详见 `.docs/配置说明.md` terrain 节与
  开发计划 P5 改版记录。（旧"亮度带"编码已废弃；旧图备份在 `data/legacy_old_encoding/`。）
- 首都放置：8 个，随机抽陆地格；与已放首都欧氏距离 < 28 则重抽；全部置 `city=1`。
- 清理：海上城市 `city=0`；统计 `total_citys`。
- **屏幕朝向**：`toscreeny = (Map_y - y)*15`（Y 翻转）。世界坐标系 y=0 在屏幕底，
  `mmap` 的 j=0 行在屏幕底。

## 2. 单位（兵）属性与类型

六个类型（`type`）：普通0 / 先锋1 / 开拓2 / 激光3 / 爆炸4 / 地雷5。

出生参数（`SpawnSystem::spawnArmy`）：
- 出生方向：0~2π **连续均匀随机**（原版轴向 ±45° 吸附已取消）。
- `speed = 0.3`；加成链：势力3 ×1.5 → 类型1 ×2 → 类型2且势力4 ×2 → 类型≥3 ×0.6。
- `size`：基础 1.1（config 现值 `army.baseSize=1`）；类型3 ×1.8、类型4 ×1.8、类型5 ×1.4。
- 初始 `onland=1`、`lst_move_to_land_time = ttime`。
- 无硬上限（可用 `config.debug.maxArmyGuard` 保护）。
- 每 tick 末尾**无抖动**（原版全兵微抖动已取消，改为反弹时加随机小偏置，见 `config.army.bounceJitter*`）。

先锋/开拓特性（2026-08 重置）：先锋 = 快 + 碰敌方领土 60% 不反弹（`bounceMult` 0.4）；
开拓 = 连占上下左右 4 邻格 + 山地不减速 + 山地进入概率降低（进入 0.8），敌方不反弹已取消
（`bounceMult` 1.0）。

## 3. 移动规则（`Army::move`）

网格穿越用 `find_next_xy`（见 §12）。主循环：

```
rem = speed
while rem > 0:
    resi = find_next_xy(x, y, angle, rem)     # 返回下次撞到的网格边界
    if find_and_attack(): return              # 战斗检查（每跨一格一次）
    if resi < 0:                               # -2 走完本 tick 剩余量；-1/-3 见 §12
        x,y 夹取到 [eps, Map_x]/[eps, Map_y]
        若当前格非己方 → conquer((int)x,(int)y)
        return
    if resi==0&&x<=0: angle=π-angle; continue # 左边界反弹
    if resi==1&&y<=0: angle=-angle;  continue # 上边界反弹
    if resi==2&&x>=Map_x: angle=π-angle; continue # 右边界反弹
    if resi==3&&y>=Map_y: angle=-angle;  continue # 下边界反弹
    goal_map = 该方向相邻格（用 ±eps 取整）
    # --- 山地/海陆切换（下一格为山「不管当前格是什么」都掷进入/反弹）---
    if goal 是海 && 自己 onland:              # 陆/山→海
        若自己在山地: 复原山地速度（若该兵种在山地减速；开拓不减速）
        chance = (ttime - lst_move_to_land_time + 110) * go_sea_probability / 17700.0
        if 势力3: chance *= 0.666
        if get_chance(chance): 下海（onland=0; speed/=2; rem/=2）   # 不 break（见要点）
        else: 反弹（水平撞→angle=π-angle；垂直→angle=-angle）
    else if onland && goal 是陆地:             # 陆→陆（含山）
        若自己在山地 && goal 非山: 复原山地速度（若该兵种在山地减速）
        若 goal 是山:                          # 山地骰（含山→山）
            enter = mountainEnterChance × 兵种.mountainEnterMult   # 普通/先锋 0.5、开拓 0.8
            if get_chance(enter):
                若不在山地: inMountain=1; 若该兵种减速: speed×0.5, rem×0.5
            else: 反弹; 跳过攻占
        若已通过 && goal 非己方陆地:           # 敌方阻挡骰（与山地骰独立计算）
            conquer(goal); if 开拓兵: 连占上下左右 4 邻格
            reb = 兵种.bounceMult; if 势力4: reb*=0.6   # 先锋 0.4=60% 不反弹；其余=1 必反弹
            if get_chance(reb): 反弹
    else if goal 是陆地 && 自己不在陆上:       # 海→陆 登陆
        若 goal 是山: 先掷山地骰（失败→反弹留海，不登陆）
        通过后: onland=1; 复原陆速（speed/0.5, rem/0.5）; lst_move_to_land_time=ttime
        若 goal 是山: 进山（若该兵种减速: speed×0.5, rem×0.5）
        conquer(goal); if 开拓兵: 连占上下左右 4 邻格
x,y 夹取到 [0,Map_x]/[0,Map_y]
```

要点：
- `go_sea_probability` 初始 1，每 tick `+= sea.goSeaIncrease`（独立常量 8.5e-05；
  原 timeToUnify 推导与 `sea.timeToUnify` 键均已删除），随时间越发「海战化」。
- 下海成功时 `speed/=2`、`rem/=2`，**不 `break`**（下海后继续走完本 tick 剩余移动）。
- 登陆时 `rem*=2` 补回额外移动量，方向不变。
- 攻占发生在**每次跨格进入敌方格**（途中一格一格刷领土），`resi<0` 结束点也补一次征服。
- 开拓连占 4 邻格按**固定顺序上→下→左→右**，保证 RNG 消耗可复现。
- 山地阻挡先判（失败→反弹，不进入不征服）；敌方阻挡在征服**后**独立掷（反弹=「弹回」）。
  下一格既为敌又为山时两骰独立：非先锋（bounceMult=1.0）必反弹；先锋两骰都过才不反弹。
- 下海/反弹用的 `get_chance` 每次消耗一个随机数——保持调用次数与位置不变（影响同种子序列）。

## 4. 碰撞战斗（`find_and_attack`）

- 每跨一格，与**全池**敌方活兵比对：`distance(p,this) < p.size + this.size` → 双方 `kill(0, 对方)`，返回 1（本兵本 tick 移动中止）。
- 双方**同归于尽**；`kill` 无论 `kill_type` 都会触发死亡者自身的类型死亡效果（§5）。
- 用空间哈希等价替换 O(n²)，但**同一格内只判定一次**的语义保留（「本格已处理集合」防重复击杀一兵）。
- tick 内新出生的兵从**下一 tick** 才开始移动。

## 5. 死亡与死亡效果（`Army::kill` + 触发条件）

死亡效果**不区分死因**（战斗、爆炸、激光均触发），按死者的 `type` 与势力：

| type | 效果 |
|---|---|
| 3 激光 | 向击杀者方向 `add_effect(..., type2, creator=自身)` 激光；`belongi==5`（绿）时额外 ±π/11 两条（共 3 条）。激光角 = `get_angle(死位, 击杀者位)`。 |
| 4 爆炸 | `add_effect(..., type0)`，半径参数 `belongi==6`（橙）→ 4.08，否则 2.4。 |
| 5 地雷 | `add_effect(..., type1)` 地雷（布设）。 |

战斗/爆炸/激光处均传入非空击杀者；地雷超时爆炸的 `creator_id` 传地雷自身的 creator（即原布设兵）。

## 6. 特效（`Effect`）规格

通用：求解前先**快照**特效列表；遍历中新建的特效（如地雷引爆的爆炸）与 tick 末
`DeathSystem::flush` 产生的特效均**下一 tick（tt=1）才求解**。特效绘制见 §9。

**爆炸（type0）**：
- 半径参数 `lsdouble1`（bomb_range）：爆炸兵橙6 → 4.08，否则 2.4；地雷引爆 1.1/1.43（紫7）。
- `r = sqrt(tt+1) * bomb_range`（绘制同用此公式）。
- `tt%2==0` 时：征服以 (x,y) 圆心半径 r 内所有格（判定用 `distance(i+0.5, j+0.5, x, y) < r`）；击杀半径内敌方活兵。
- `tt>8` → 消亡。总生命周期 9 tick。

**地雷（type1）**：
- 静态半径 1.4，布设后 `tt>=600`（10s）起每 12 tick 检测：敌方兵距雷 `< r*1.1 + 兵size` → 引爆（bomb_range 紫7→1.43 否则 1.1），雷消失。
- 探测循环**有 break**：每雷每次检测至多产出一个爆炸特效。
- `tt>=3600`（60s）→ 直接爆炸，半径统一为**引爆半径**（紫7→1.43、否则 1.1；原版超时更大半径的差异已取消）。
- 引爆瞬间 `add_effect(..., type0, creator=布设兵)`。

**激光（type2）**：
- 寿命：绿5 → 33 tick，否则 22。长度：绿5 → 45，否则 30。
- 从 (x,y) 沿 `lsdouble1`（angle）用 `find_next_xy` 逐格延伸；**遇地图边界或「进入非己方陆地」停止**（继续穿过海与己方领地）。
- 每 tick 击杀「到光束线段的垂直距离 ≤ 兵size+0.1」的敌方活兵；光束长度渐进增长，每 tick 至多 +2。
- 征服时机：**光束提前停下（遇敌领土/边界）时征服尖端格**；自由增长时不征服。
- 绿5 的 ±π/11 两条同规则（各自独立 angle）。

## 7. 经济与产兵

**经济（P14 朴素逐 tick 收入模型，现行）**：每 tick 每势力
- `landIncome = perLandIncome × landCount`（普通领地，含城市基建格）；
- `cityIncome = perLandIncome × cityBaseMult × Σ level^alpha`（归城市 owner）；
- `capitalIncome = capitalBase`（flat 加成——首都的 level^alpha 收入已含 cityIncome，勿重复计率）;
- 总 = 三者之和 × 势力 `economyGainMult`（P7 增益）。灭亡势力零收入。
- 城市基建格双计：既是普通领地又属城市，勿去重。数值见 config `economy` 段。

**产兵（留存值 + 公平调度堆，现行）**：
- economy = **库存**（每 tick 累加收益、产兵扣成本，≥0）。
- 维护最小堆：元素 `{兵种编号, 单价(=army_cost), 该兵种累计花费}`，排序键 = 已花费 + 单价
  （开局按单价排 → 先产便宜普通兵；产兵后键值升高 → 兵种随平衡多样化）。每逻辑帧
  库存 ≥ 堆顶单价 → 出堆产该兵、库存扣单价、累计花费 +单价再入堆，直至库存 < 堆顶单价。
- 无城市势力不产兵。实现：`ProductionSystem::produce` + `Faction.producedCost`。

**回合顺序**：初始化 `random_shuffle(0..7)`；每 tick 执行两次
`swap(faction_solve_order[GetRand(7)], …)` 后依次求解。经济累积不消耗 Rng；
产兵每次 `spawnArmy` 消耗一个角度随机。

**势力特色（P11 后，不影响价格）**：

| 势力 | 颜色(RGB) | 能力 |
|---|---|---|
| 1 红 | 255,0,0 | — |
| 2 黄 | 255,255,0 | — |
| 3 青 | 0,255,255 | 全兵速 ×1.5；下海概率 ×0.666 |
| 4 蓝 | 0,85,255 | 全兵攻敌领地反弹概率 ×0.6（多 40% 不反弹）；开拓兵速 ×2 |
| 5 绿 | 0,255,0 | 激光 3 条、寿命 ×1.5、长度 ×1.5 |
| 6 橙 | 255,127,0 | 爆炸半径 4.08（+70%） |
| 7 紫 | 127,0,255 | 地雷爆炸半径 ×1.3（引爆 1.43；超时同引爆半径） |
| 8 品红 | 255,0,255 | 攻占新城市时 60% 概率在该城免费产一个普通兵 |

- 势力 0 灰 (127,127,127) 仅作初始填充，`alive=0`；其 `landCount` 初始 = 无主领地数。
- 势力特色以增益形式实现（`initialFactionBuffs`），不再含任何造价修正。

## 8. 势力征服（`conquer/insert_city/remove_city`）

- `conquer(x,y)`：越界忽略；同势力忽略；若 `city`：旧主 `remove_city`、新主 `insert_city`，
  且**势力8** `get_chance(0.6)` 免费产普通兵于 (x+0.5,y+0.5)（**init 阶段除外**：
  `ConquerContext.freeArmyEnabled=false` → 无开局免费兵）；若 `land`：旧主 `flands--`、
  新主 `flands++`、`belongi=新主`。
- `insert_city`：`mmap[x][y].city` 为真、`id∈[1,8]`、去重后追加到 `citys`。
- `remove_city`：找到后与末位 `swap` 再 `fcitys--`。
- 城市列表为 `std::vector<CityRef>`（无上限）。

## 9. 渲染基准

坐标变换（原版精确移植）：
- `toscreenx(x) = x*15 + 600`；`toscreeny(y) = (95 - y)*15`。窗口尺寸取
  config `render.windowWidth/windowHeight`（现值 2560×1600）。
- 背景黑（海即背景黑）。

**地图**：每格 15×15：
- 海：填黑。
- 陆地非城市：`mix_color(势力色, 白(255,255,255), 0.6)`（rate 为第一色占比）。
- 城市（P5 改版视觉）：陆地基色 + 线条城贴图（`data/city.png`，tint
  `mix_color(势力色,黑,0.85)` 略深）；山格再叠加线条山贴图（`data/mountain.png`，
  tint `mix_color(势力色,黑,0.08)` 近黑），山下城上。
- `mix_color` 逐通道 `c1*rate + c2*(1-rate)`。

**兵**：`army.png` 256×256，8 列 × 8 行 32×32 子图，行 type、列 faction-1。绘制：以
`(toscreenx, toscreeny)` 为中心，48×48 拉伸，alpha blend，不翻转。第 6、7 行子图供激光特效复用。
（双色势力渲染由 `TwoToneTintCache` 按主副色软件合成，纯渲染层、sim 不变，见开发计划 P16。）

**特效**：
- 爆炸：半透明圆，`半径 = r*15`，`alpha = (9-tt)/9*255`，填充色 = 势力色。
- 地雷：地雷子图 48×48；`tt>=600` 且 `tt%12 ∈ {0,1,2,10,11}` → alpha 220，否则 alpha 60（闪烁）。
- 激光：火花子图以 `(toscreenx,toscreeny)` 为中心随机旋转；光束子图以**图像上边中点 (16,0)
  为旋转中心**，横向 0.5（宽 16px）、纵向 `15*final_length` px，旋转角 `-angle-π/2`
  （SDL 等价：`SDL_RenderCopyEx(tex, rect, center=(16,0), angle_deg=(-angle-π/2)*180/π, flip=无)`）。
  分层绘制：光束先画、火花（BLEND）盖其上（ADD 发光在本机 direct3d logical-size 下静默失效，弃用）。
  绿势力三束同源，中心束最后画。

**排行榜**：ImGui 左栏面板呈现，按 `flands` 降序，样式与原版面板一致（不要求逐像素一致）。

## 10. 主循环与时间基准

新版固定步长：模拟每 1/60s tick 一次，渲染独立帧率。每 tick 系统顺序：
Movement → Combat → Effect → Economy → Production → Death（flush 死亡特效）；
势力8 免费兵经 `pendingSpawns` 在军队阶段后、经济阶段前落地。
`ttime` 即逻辑帧计数（60fps 下 1 tick = 1/60s），特效定时（600=10s、3600=60s）以 tick 计。
ESC 双击 = 非阻塞暂停/继续（另有空格暂停）。

## 11. 相对原版的行为定夺清单

以下均为 2026-08 用户定夺/实现定案的行为改动（相对原版 DxLib 行为）：

1. 下海**去掉 `break`**：不再丢弃本 tick 剩余移动；`speed` 与 `rem` 同步减半生效。
2. 地雷**超时**爆炸半径统一为**引爆**半径（含紫7：1.95→1.43）。
3. `find_next_xy` 撞角改**反向（+π+微偏置）**、返回 -3（原随机角 + 返回 -1）。
4. 中立势力0 `landCount` 初始 = 无主领地数（原从 0 起减负）。
5. 势力8 开局免费兵移除（对局内攻城免费兵保留）。
6. 出生方向改连续均匀随机（取消轴向吸附）；取消每 tick 微抖动，改反弹时小偏置。
7. 新出生的兵下一 tick 才开始移动。
8. 特效 tt=1 才求解（新建/flush 的特效不在当 tick 参与求解）。
9. 地雷探测循环加 break：每雷每次检测至多一个爆炸特效。
10. 激光仅在光束提前停下（遇敌领土/边界）时征服尖端格，自由增长不征服（以代码为准）。
11. P14 经济模型取代原幂公式魔法经济；P11 移除 costDiv 价格修正（势力特色改为偏好/增益）。
12. P5 地形基图 RGB 概率权重编码取代亮度带编码。
13. 消息无限留存（取消自动消失/渐隐设计）。

## 12. 关键数学工具

- `get_chance(p)`：`GetRand(9999999)/10000000.0 < p`。
- 角度：新版 `MathUtil::getRandomAngle` 连续均匀 `[0,2π)`。
- `get_angle`、`distance`、`mix_color`：直接照抄原版。
- `find_next_xy(x, y, angle, remlength)`：返回本次移动先撞到的网格边界方向并更新位置/余长：
  - 返回 0/2 = 水平边界（x1/x2），1/3 = 垂直边界（y1/y2）；更新 `x/y` 至该边界，`remlength -= res`。
  - 返回 `-2`：整段走完（`x += rem*cos, y += rem*sin, rem=0`）。
  - 返回 `-3`：两个方向边界距离相等（撞角）→ `angle += π + 4*kEps` 反向，不动位置；
    调用方：兵 `continue` 继续移动、激光 `<0` 即停。微小偏置打破格心对称，防止重复撞角卡死。
  - 含 `|x1-x|<eps → x1--`、`|y1-y|<eps → y1--` 的 eps 前处理。
- `point_distance_from_segment`（激光用）。

这些纯函数是单元测试重点，逐分支覆盖。
