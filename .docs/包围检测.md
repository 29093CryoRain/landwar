# CUSUM + 离线块自助法阈值校准

## 1. 设定

- 观测：\(X_t\in\{0,1\}\)，\(t=1,2,\dots\)
- 目标：检测当前是否进入稳定状态 \(p=E[X_t]>c\)
- 允许均值和间隔上界发生未知变点
- 一旦进入 \(p>c\)，均值和上界不再变化
- 过程有记忆、非泊松
- 在线检测不依赖间隔上界 \(M\)

## 2. 在线 CUSUM 检测

参数：

- \(c\)：目标阈值
- \(\eta>0\)：容忍裕度
- \(h\)：报警阈值，由离线块自助法校准

初始化：

\[
C_0=0
\]

每次观测 \(X_t\) 后更新：

\[
C_t=\max\left(0,\;C_{t-1}+X_t-c-\eta\right)
\]

检测条件：

\[
\boxed{C_t\ge h \;\Longrightarrow\; \text{报警：当前已进入 }p>c\text{ 的稳定状态}}
\]

若 \(C_t<h\)，继续观测。

可选确认：

- 要求连续 \(K\) 步满足 \(C_t\ge h\) 后再报警。

## 3. 离线块自助法校准 \(h\)

输入：

- 基准数据 \(X_1,\dots,X_N\)，来自未进入目标状态的 regime，即 \(p\le c\)
- 块长 \(B\)
- 模拟次数 \(R\)
- 误报率 \(\alpha\)

步骤：

1. 选择块长 \(B\)，要求 \(B\) 大于记忆长度或混合时间。
2. 将基准序列划分为长度 \(B\) 的块，可重叠。
3. 对 \(r=1,\dots,R\)：
   - 从块中有放回重采样，拼接成与基准数据同长的序列 \(X^{(r)}\)。
   - 在 \(X^{(r)}\) 上运行 CUSUM，参数为 \(c,\eta\)。
   - 记录最大统计量：
     \[
     M_r=\max_t C_t^{(r)}
     \]
4. 取 \(h\) 为 \(\{M_1,\dots,M_R\}\) 的 \(1-\alpha\) 分位数。

输出：

\[
\boxed{h}
\]

## 4. 在线算法流程

```text
初始化 C = 0

每观测一个 X_t：
    C = max(0, C + X_t - c - eta)

    若 C >= h：
        报警“当前已进入 p > c 的稳定状态”
    否则：
        继续观测
```

## 5. 复杂度

| 部分 | 时间复杂度 | 空间复杂度 |
|---|---|---|
| 在线 CUSUM | \(O(1)\) / 步 | \(O(1)\) |
| 处理 \(T\) 个观测 | \(O(T)\) | \(O(1)\) |
| 离线块自助法 | \(O(RN)\) | \(O(N)\)，分块可降为 \(O(N/B)\) |

块自助法可并行。

## 6. 参数建议

- \(\eta\)：取 \(0.05c\)、\(0.1c\)，或按最小可检测超出量设定。
- \(B\)：大于记忆长度或混合时间。
- \(R\)：\(1000\) 至 \(10000\)。
- \(\alpha\)：\(0.01\) 或 \(0.05\)。
- 确认步数 \(K\)：按误报要求选择。

## 7. 说明

- 不依赖间隔上界 \(M\)，因此 \(M\) 变化不影响检测。
- CUSUM 的 \(\max(0,\cdot)\) 自动遗忘旧 regime。
- 有记忆时，块自助法通过块内重采样保留依赖结构。
- 若进入 \(p>c\) 后过程稳定，CUSUM 将累积正漂移并最终报警。

## 8. 在本项目中的落地（盟友边界闸门）

落地规格见 `.docs/兵运动与盟友系统开发文档.md` §12；本节只说明本文的算法如何映射到游戏。

- **观测 \(X_t\)（每兵每 tick）** = 该 tick 内"盟友边界反弹"的次数（0/1/多次）。盟友边界反弹 =
  目标格是盟友陆地、原格不是盟友陆地时的任何反弹（河骰失败、山骰失败、盟友规则 2 的确定反弹）；
  规则 1/3 的直接穿过、盟友领土内部的河/山反弹、敌方/中立/地图边界的反弹都不计入。
- **"结合速度"= 把速率换成"每格"**。本文的 \(r\) 单位是次/tick，而单位移动 \(v\) 格/tick 时
  \(r\propto v\)，直接用固定 \(c\)（次/tick）会让快兵更早报警、慢兵更晚。故把状态量写成
  \[
  S(t)=\sup_{s\le t}\bigl\{N(t)-N(s)-c\,(D(t)-D(s))\bigr\},\qquad D=\text{累计行进距离},
  \]
  实现为每 tick \(S\leftarrow\max\bigl(0,\;S-(c+\eta)\,v_t\bigr)+X_t\)，其中 \(v_t\) 是本周期的步长
  （= 该兵速度；过河停顿时取结转步长）。此时 \(c,\eta\) 的单位是**次/格**，判据与兵速无关。
- **判据与放行**：\(S\ge h\) → 该兵认定为"被盟友边界持续围困"；下一次进入盟友领土的
  **归属判定**（河/山骰之后）放行一次：不反弹、不征服，并把 \(S\) 清零。成功进入盟友领土也清零
  \(S\)（尝试成功即压力解除）。河/山骰仍独立判定——闸门只覆盖"盟友不可占领"这一条。
- **参数**：本文 §6 的离线块自助法只用于**离线标定 \(h\)**；游戏内只跑在线 CUSUM，
  参数走 `config.allyGate`（`leakPerCell` = \(c\)、`tolerancePerCell` = \(\eta\)、
  `alarmThreshold` = \(h\)）。无联盟时无观测 → \(S\equiv 0\)，行为与旧版逐位一致。
- **边界情形**：单位中途死亡则随实体销毁；盟友关系一局内固定；多单位各自独立统计；
  单 tick 内多次反弹也计入（先结算泄漏、后逐次 +1，故同 tick 可以既越阈又放行）。
