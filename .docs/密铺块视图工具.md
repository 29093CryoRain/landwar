# 密铺块视图工具（tools/view_spec.py）

> 一个纯 Python + matplotlib 的**肉眼核对工具**：读取 `data/tiling_specs_arch.json` /
> `data/tiling_specs_laves.json`，渲染某个密铺的**单个平移块**，并标注每个顶点的
> **valency**（把块平铺到全平面后，有多少个基础格相交于该点）。
> 用途：核对 spec 块的拓扑/方向是否正确；据 valency 判断哪些顶点可作城市中心。
> 不进入构建、不影响运行，仅开发时手工使用。

---

## 1. 用法

在**项目根目录**运行（脚本以 `data/` 相对 CWD 解析，与工程约定一致）：

```bash
python tools/view_spec.py                       # 交互菜单，列出所有密铺
python tools/view_spec.py --list                # 打印全部密铺名，直接退出
python tools/view_spec.py laves_4612            # 渲染指定密铺 -> tools/blocks/block_laves_4612.png
python tools/view_spec.py --all                 # 渲染所有密铺到 tools/blocks/（block_<name>.png）
python tools/view_spec.py --all -o DIR          # 渲染所有密铺到指定目录 DIR
python tools/view_spec.py --help                # 用法说明
```

参数：
- `name`：密铺名（见 `--list`）。可在一行传多个。
- `--all` / `-a`：渲染全部密铺。
- `-o DIR`：输出目录（默认 `tools/blocks/`，自动创建）。缺省时所有图统一存到该目录。

## 2. 图面含义

- **彩色多边形** = 中央块 `(i,j)=(0,0)` 内每个基础格（24 色循环），中心标格下标。
- **浅灰多边形** = 环绕中央块一圈（`RING=1`）的邻居块格，仅作 context——中央块格子常
  **越出周期盒**（overhang），画邻居圈可看到它伸出后与相邻块的交叠，从而"显示全"。
- **红色方框** = 中央块的基本周期盒 `W`×`H`（四角 `(0,0)`、`W`、`W+H`、`H`）。
  坐标轴范围取**中央块格的真实跨距**（含 overhang），不再裁剪。
- **每个顶点一个圆点**，标注数字 `n` = **valency**（该点在全平面被多少格共享）。
  颜色按 valency 映射（见 `VAL_COLORS`）。

### 2.1 valency 与「可作城市中心」的关系

对 Laves 类（尤以 `laves_4612` 为例，三角格为 30°-60°-90° 直角三角形，**顶点角 = 其对边
边长决定**：对边=短直角边→30°、对边=长直角边→60°、对边=斜边→90°）：

| valency | 顶点角 | 含义 | 可作城市中心 |
| :---: | :---: | :--- | :--- |
| **6** | 60° | 6 格相交（6×60°=360° 满周），平铺后连通 | **L12** 城 |
| **12** | 30° | 12 格相交（12×30°=360° 满周），跨块相邻块聚合 | **三角形 L6** 或 **另一 L12** 城 |
| **4** | 90° | 4 格相交（4×90°=360° 满周） | **矩形 L6** 或 **L4** 城 |
| 其他 | — | 如 laves_31212 等其它拓扑 | 按「异种地图开发思路.txt」对应 |

> 说明：单块内某些 valency 顶点**只聚合了半周**（如 30° 顶点单块只见 6 个），
> **块平铺延展后补足**——这正是「标了 6 的节点延拓其他块后成为可用 L12」等判断的来源。
> 该工具按 5×5（`nb` 参数）块邻域平铺统计 valency，故已把跨块补足后的真实值标出。

## 3. 依赖与定制

- 依赖：`python3` + `matplotlib`（渲染走 `Agg` 后端，无 GUI）。
- 定制点：
  - `RING`：中央块四周画的邻居圈数，默认 1（3×3）。
  - `nb`（`valency_map` 形参）：平铺邻域半径，默认 2（5×5），足够补足跨块顶点。
  - `VAL_COLORS`：valency → 颜色映射。
  - `DEF_DIR`：缺省输出目录，默认 `tools/blocks/`。
  - `draw_block(ax, spec, title, ring, annotate, labels)`：可直接复用画到自己的 `Axes`。

## 4. 维护说明

- 数据源只有 `data/tiling_specs_*.json`；脚本**不写回**任何数据。
- 新增密铺类型时无需改脚本——`--list` / `--all` 自动覆盖。
- 若非想核对三角形顶点角，`angle_at_vertex`（已留）可给出顶点对边边长，用于 30/60/90 判定。
