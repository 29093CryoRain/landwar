# 地图尺寸比例映射（乘积保持）算法与工具说明

> 对应功能：半正/Laves 密铺随机地图的「长/宽 → 周期域列/行」映射。
> 让用户输入的 `长×宽` 精确等于地图总格数（`总格数 = B·cols·rows`），且**长宽比**尽可能贴近
> 用户输入（`长/宽 ≈ 实际长/宽`），同时输入必须是某整数倍数（小于等于 16，保证菜单 +/- 步进可用）。

---

## 1. 问题背景与约束

密铺有一个**平移周期域**（fundamental domain），含 `B` 个基础格。地图 = `cols × rows` 个周期域，
总格数 = `B·cols·rows`。用户输入 `(a, b)` 后要得到 `(cols, rows)`。

设 `s, t` 为一个平移块内的格行列数（`s·t = B`），`u = wx/s`、`v = hy/t` 为**每格世界宽/高**
（`wx, hy` 为周期域世界长/宽；斜周期域取轴对齐分量）。需要满足：

| # | 约束 | 含义 |
|:-:|------|------|
| ① | 乘积保持 | `a·b = c·d`（`c = cols·s`、`d = rows·t`） |
| ② | 倍数约束 | `c` 为 `s` 的倍数、`d` 为 `t` 的倍数 |
| ③ | 比例正相关 | `c ∝ a`、`d ∝ b`（调长只改 cols、调宽只改 rows） |
| ④ | 长宽比 | `(c·u)/(d·v) ≈ a/b` |
| ⑤ | 输入间距小 | `max(Ra, Rb) ≤ 16`（`Ra/Rb` 为 `a/b` 须满足的倍数，即菜单步进） |

---

## 2. 数学推导（算法一 / 算法二解耦）

### 2.1 正比例 ⇒ p/q = √(v/u)

令 `c = (p/q)·a`、`d = (q/p)·b`（`p,q` 互质，正比例且保积）。代入 ④：
`(c·u)/(d·v) = (p²/q²)·(a/b)·(u/v) ≈ a/b` ⇒ **最优比例因子 `p/q ≈ √(v/u)`**，仅由常数 `u,v`
决定，与输入 `a,b` 无关。

### 2.2 输入限制 `Ra, Rb`

为保证 `c = (p/q)a` 为整数且是 `s` 的倍数、`d` 为 `t` 的倍数，输入须满足：

```
Ra = q·s / gcd(s, p)      // a 必须是 Ra 的倍数
Rb = p·t / gcd(t, q)      // b 必须是 Rb 的倍数
```

### 2.3 算法二（在线映射，C++ `chooseTableDomain`）

```
a' = ceil(a / Ra) * Ra    // 输入合规化（向上取整到 Ra 倍数）
b' = ceil(b / Rb) * Rb
c  = p·a' / q
d  = q·b' / p
cols = c / s
rows = d / t
```

由 `Ra, Rb` 的构造，`a'` 是 `q` 的倍数、`b'` 是 `p` 的倍数 ⇒ `c, d` 为整数且满足倍数约束；
`c·d = a'·b'`（乘积保持）；`c ∝ a`、`d ∝ b`（正比例）。

## 3. 算法一（离线预生成，工具 `tools/gen_table_domain_params.py`）

离线对每个密铺枚举 `s·t = B` 的正因式分解与互质 `(p, q)`，强约束 ⑤ `max(Ra,Rb) ≤ K_MAX_GAP(=16)`，
按 `err = |ln(p/q) − ½·ln(v/u)|` 择优（主）、`max(Ra,Rb)` 次优、块方正度 `|s−t|` 再优。

### 3.1 用法

```bash
python tools/gen_table_domain_params.py            # 打印全部密铺参数（s,t,p,q,Ra,Rb）
python tools/gen_table_domain_params.py --emit     # 打印可直接替换 Tiling.cpp tableDomainParams 的 C++ 表
python tools/gen_table_domain_params.py --verify   # 断言全部约束（①②③④⑤⑥(s*t==B,gcd=1)）满足
```

脚本从 `data/tiling_specs_arch.json` / `data/tiling_specs_laves.json` 读取各密铺当前
`W=(wx,·)`、`H=(·,hy)`、`B`（`u = wx/s`、`v = |hy|/t`、目标 `p/q ≈ √(v/u)`）。

## 4. 代码中的已实现位置

| 算法 | 位置 | 说明 |
|------|------|------|
| 算法一（解析） | `tools/gen_table_domain_params.py` | 离线枚举 + 择优，结果硬编码进 `tableDomainParams` |
| 算法一（结果存储） | `src/world/tiling/Tiling.cpp::tableDomainParams` | `static TableDomainParams kTable[...]` |
| 算法二（在线映射） | `src/world/tiling/Tiling.cpp::chooseTableDomain` | `a'→c→cols、b'→d→rows` |
| 输入限制（UI 步进） | `src/world/tiling/Tiling.cpp::tableInputRestriction` | 返回 `(Ra,Rb)`；菜单据此设 `+/-` 步进与夹取 |
| 消费方 | `src/world/MapGenerator.cpp::generate`、`src/world/Map.cpp::configure` | 均调 `chooseTableDomain`，保证 lwmap 头尺寸一致 |

> 修改任意密铺 `tiling_specs_*.json`（改变 `wx/hy/B`）后须**重跑** `gen_table_domain_params.py --emit`
> 并同步替换 `tableDomainParams`（否则 `s·t=B` 与 ④ 失效）。

## 5. 约束校验

`gen_table_domain_params.py --verify` 对每个密铺断言：
① `s·t = B`；⑥ `gcd(p,q)=1`；⑦ `Ra=qs/gcd(s,p)`、`Rb=pt/gcd(t,q)` 一致；⑤ `max(Ra,Rb)≤16`；
②③ 对若干测试输入，`c|s`、`d|t`、`a'·b'=c·d`、`cols/rows` 为整数；④ 纵横比偏差 ≤ 30%。
单测 `tests/test_tiling_table.cpp` 的 `*MapGeneration*`/`SnubTilingsGenerateLoadAndCellRoundTrip`
同时用真实的 `chooseTableDomain` + 生成加载验证 `总格数 = B·cols·rows`、`= 用户长×宽（合规输入）`。
