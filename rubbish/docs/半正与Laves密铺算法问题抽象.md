# 半正密铺与其对偶（Laves）的算法问题抽象文档

> 目的：把"游戏项目中 4 种尚未支持的平面密铺"从游戏背景中剥离，抽象为一个纯数学/算法
> 问题，供咨询专业人士（几何/离散几何/计算几何方向）。文档说明问题、约束、算法需要
> 提供的服务、现状与难点。所有数值与结论均来自项目内实际工具的实验验证。

---

## 1. 问题概述

**目标**：对 4 种平面密铺（2 种阿基米德半正密铺 + 其 2 种对偶 Laves 密铺），产出一套
"表驱动"描述，使下游程序能：

1. 由该描述重建**无限密铺的有限周期域**（fundamental domain / unit cell）；
2. 提供一系列几何与拓扑查询服务（见 §4）；
3. 对半正密铺计算其对偶密铺（Laves）的周期域与面数据。

这 4 种密铺是：

| 名称 | 顶点构型 | 面的种类（按边数） | 备注 |
| :--- | :--- | :--- | :--- |
| Arch 3.3.3.3.6 | 4 三角形 + 1 六边形共点 | 三角形、六边形 | 数量比 三角:六边 = 8:1 |
| Arch 3.3.4.3.4 | 三角形与正方形交替共点 | 三角形、正方形 | 数量比 三角:正方 = 2:1 |
| Laves 3.3.3.3.6 | 五边形（对偶于上） | 单一五边形 | 边序 a,a,a,b,b |
| Laves 3.3.4.3.4 | 五边形（对偶于上） | 单一五边形 | 边序 a,b,b,b,b |

说明：现有工具已支持另外 5 种半正（3.3.4.3.4 与 3.3.3.3.6 之外的）及 5 种 Laves；还有一种半正及其对偶不需考虑，
本问题聚焦剩余 4 种中"扭棱类（snub）"半正密铺及其五边形对偶。
（3.3.3.4.4 明确不做；3.3.4.3.4 的顶点构型为三角形/正方形交替，与 3.3.3.3.6
同属"同一面型多标签"的扭棱类难点家族。）

---

## 2. 术语与记法

- **顶点构型（vertex configuration）**：`[n1, n2, ..., nk]` 表示平面密铺中每个顶点周围
  按环序排列的 k 个面，第 i 个面是 ni 边形。例：`[3,3,3,3,6]` = 每个顶点周围 4 个三角形
  与 1 个六边形。
- **阿基米德半正密铺**：所有顶点等价（同一顶点构型）、所有面都是正多边形、但允许多种
  面型的平面密铺。
- **对偶密铺（Laves / Catalan）**：对半正密铺取几何对偶（每个面的中心为对偶顶点，每对
  相邻面中心连边），得到"顶点等价、面多种"的密铺。半正密铺的对偶 = Laves 密铺。
- **周期域 / 基础格（fundamental domain）**：无限周期密铺的一个平行四边形周期
  （由两个周期向量 W, H 张成），连同域内"基础格"（base cells）的位置与形状。整个密铺
  是周期域的整数平移复制。
- **面标签（edge label / face sequence）**：一个多边形的**环序边标签**，即沿多边形边界
  依次列出每条边另一侧的面型。例：三角形标签 `[3,3,6]` 表示三边外侧分别是三角、三角、
  六边。**同一面型可以有多种合法标签**（取决于局部上下文），这是本问题的核心难点之一。

---

## 3. 已知可行方法（对照）与难点定位

### 3.1 已支持 10 种密铺的做法（现状基线）

项目现有工具（Python）用**边传播**构造周期域：

1. 对每个面型 n，枚举其合法**环序边标签**（valid sequences）：由顶点构型
   `[n1..nk]` 的循环结构推导——与面型 n 相邻的面型集合是确定的，但标签是这些面型的
   环序排列，可能有多种。
2. 从种子多边形出发，沿未占用的边不断"贴"新多边形（新多边形按该边共享、其余边按
   正多边形角度绕行构造）。
3. 用"定向边所有格"检查闭合（每条边恰好被两个面反向共享），并用顶点集平移匹配找
   最小周期向量 (W, H)。
4. 半正周期域得到后，取每个顶点周围面中心的多边形 → 对偶 Laves 周期域。

对非扭棱类（如 3.4.6.4、3.12.12 等），每种面型只取**一种**规范标签即可传播成功。

### 3.2 扭棱类的失败现象（实验证据）

对 `[3,3,3,3,6]`（三角 + 六边）：

- 三角形的合法标签有 **2 种**：`[3,3,3]`（三边都邻三角形）与 `[3,3,6]`（两三角一六边）；
- 六边形的合法标签唯一：`[3,3,3,3,3,3]`（六边都邻三角形）。

实验 1：只用标签 `[3,3,3]` 传播 → 几何"成功"（传播到数千多边形、检测到周期），但
**产出的根本不是目标密铺**：
- 顶点实际构型全部退化为 `(3,3,3,3,3,3)`（纯三角形密铺），六边形全部孤立悬空、
  不参与任何顶点（六边形真实邻居为空）；
- 这不是"标签错误"或"对偶面错误"这类局部问题，而是**全局密铺错误**——单标签边传播
  在这个构型下根本无法长成目标密铺。

实验 2：只用标签 `[3,3,6]` 传播 → **边冲突**（某个定向边被两个面重复占用），直接失败。

结论：**扭棱类的面型-标签不是一一对应**，同一面型在不同局部上下文中携带不同标签，
且两种标签必须**同时、按局部几何正确混合**地参与传播；"每面型取单一规范标签 +
边传播"既不能闭合（实验 2）也不会收敛到目标密铺（实验 1）。这是首要难点。

对 `[3,3,4,3,4]` 同族：三角形的合法标签 `[3,4,4]` 与 `[4,4,4]`（或依构型取
`[3,3,4]`/`[4,4,4]` 等混合）同样需要按局部上下文混合；单取任一标签同样退化或冲突。
（实验：单标签传播 → 顶点退化为纯三角构型 `(3,3,3,3,3,3)` 或边冲突失败。）

### 3.3 问题形式化

给定顶点构型 `[n1,...,nk]`（k≥3，所有 ni ≥ 3，满足正多边形内角和的铺满条件），
求：

**(P1) 无限密铺的周期域**：最小周期向量 W, H 与域内有限个基础面（位置、形状、边标签），
使整数平移复制恰为整个密铺，且所有顶点满足给定构型。

**(P2) 对偶密铺周期域**：由 (P1) 求 Laves 对偶的周期域（每个顶点 → 一个对偶面，
对偶面 = 该顶点周围各面中心的环序多边形；要求对偶面在周期域内正确归并）。

**(P3) 服务查询**（见 §4）：对 (P1)/(P2) 的结果提供几何与拓扑查询。

难点集中在 (P1) 的**标签分配一致性**与**手性选择**。

## 4. 下游程序需要的服务（算法接口要求）

抽象掉游戏背景，下游是一个"平面密铺几何引擎"，需要以下服务（对每种密铺）：

1. **周期域枚举**：返回周期向量 W, H 与基础面列表。每个基础面给出：
   - 面型（边数 n）；
   - 顶点坐标（相对域原点，float，需满足方向规范——见 §5.1）；
   - 环序边标签（每条边外侧的面型，用于校验与对偶）。
2. **覆盖性查询（world → cell）**：给定世界坐标 (x, y)，返回该点所属的"格"
   （基础面 + 周期平移坐标 (r, c)）。要求对任意坐标快速且无歧义。
3. **格 → 多边形**：给定格标识，返回其多边形顶点（渲染用）。
4. **邻接查询**：给定格，返回其各边外侧的邻格（含周期环绕跨边界的处理）。
5. **锚格朝向变换**：同一面型的多个基础格可能具有不同朝向（旋转/镜像）；给定任意
   基础格 b，求它相对"参考格"（同面型第一个基础格）的变换（旋转角 + 是否镜像），
   使"形状表偏移"能按锚格朝向正确解析。**要求：同一面型的每种朝向都能被无歧义识别**
   （对五边形等低对称面尤其重要）。
6. **对偶构造**：给定半正周期域，产出对偶 Laves 周期域（含面的全等性校验）。
7. **边界一致性（wrap-around）**：周期域四边需自然贴合（地图左右/上下环绕时跨边邻接
   正确），且面/边/顶点计数在环绕下自洽。
8. **方向规范**：整体可旋转一个固定角度使密铺满足预先声明的方向约束（如"某类边竖直、
   某类对角线水平"），且旋转后周期向量/基础面一致变换。
9. **确定性**：所有输出由 (密铺类型, 种子) 唯一决定（下游 RNG 依赖顺序固定）。

现有引擎已满足 2–8 中的大部分（对已支持的 10 种密铺）；对 4 种新密铺，第 1、5、6 项
需要新算法，其中第 1 项（周期域构造）是根本。

## 5. 约束与规格（来自下游需求）

### 5.1 几何约束

- **边长**：半正密铺各正多边形边长统一为 L（由面面积归一化决定，例如每个 Laves 面
  面积 = 1 或每个半正面平均面积 = 1，见各密铺规格）。周期向量由 L 与构型唯一确定。
- **方向规范**：对每种密铺，文档规定了可旋转到的规范朝向（例如"六边形仅正上下方有
  顶点"、"斜边竖直且不存在水平斜边"）。引擎需能输出满足该朝向的周期域。
- **面积**：Laves 密铺每个面面积必须为 1（用于城市等级 = 面积和的语义）。

### 5.2 拓扑约束

- **数量比**：周期域内各面型数量比 = 无限密铺的数量比（例如 3.3.3.3.6 三角:六边 = 8:1）。
- **顶点构型**：周期域内每个顶点周围的面型环序 = 给定构型（允许整体旋转/镜像）。
- **对偶全等性**：Laves 对偶的所有面必须全等（或文档明示的少数几类），作为构造正确性
  的校验准则。

### 5.3 工程约束

- 结果需序列化为 JSON 表（面：中心 + 顶点 + 边标签；周期向量），供 C++ 引擎加载。
- 算法应在普通桌面机器上数秒内完成（周期域通常 ≤ 数十个基础面）。
- 需要确定性（同输入同输出）。

## 6. 现状总结（哪些已解决、哪些是难点）

### 已解决（10 种密铺，含本问题外的 5+5）

- 边传播 + 周期检测 + 对偶导出流程已验证可用；
- 世界坐标↔格、多边形、邻接、环绕、锚朝向变换、方向旋转均已在 C++ 引擎实现并测试。

### 难点（4 种新密铺）

1. **(首要) 扭棱类的标签一致性**：同一面型（三角形）在扭棱构型中有多种合法边标签
   `[3,3,3]` / `[3,3,6]`，且两者在密铺中**必须混合出现**（局部上下文决定）。
   现有"每面型取单一规范标签 + 边传播"无法闭合（实验：单用任一种标签均失败/错误）。
   需要一种能**同时传播多种标签**、或**先传播几何再事后修正标签**、或**显式处理
   手性（左/右手）** 的构造方法。

2. **最小周期与手性**：扭棱类的周期域可能有左手/右手两种互不平移的版本；需明确
   算法选择的版本，且保证数量比与对偶面全等性。

3. **对偶面归并**：半正周期域的顶点经周期平移可能"重复"（同一几何顶点对应多个域内
   副本），对偶面需正确去重/归并（现有工具按坐标去重，但扭棱类标签错误会导致对偶面
   面积/边长不唯一——见 §3.2 实验）。

4. **低对称面（五边形）的朝向识别**：Laves 五边形对称性低，锚朝向变换的"邻格偏移集
   匹配"可能产生歧义（多个基础格偏移集在旋转/镜像下不可区分），需要更强的朝向指纹
   （如结合顶点环序、边长序列）。

### 附：一个可行的备选思路（供讨论）

对 (P1)，可以考虑**从顶点出发构造**而非从边传播：先确定周期域内顶点网格（由两个
线性无关周期向量与构型的平移群决定），再对每个顶点按构型环序连出面，最后校验边
配对与标签。或采用**图论方法**：把"面+标签"建模为带边色标签的平铺图，求满足
"顶点环序 = 构型"的最小覆盖（有限域搜索 + 周期识别）。手性可通过"标签环序方向"
（顺时针/逆时针）显式参数化。

## 7. 验证基准（构造正确性的判据）

给出任何候选解，建议用以下判据验证：

1. 周期域内面型数量比符合规格（如 8:1）；
2. 每个顶点周围面型环序 = 构型（旋转/镜像等价）；
3. 每条内部边恰被两个面共享且面型一致（边配对闭合）；
4. Laves 对偶所有面全等（单一面积；边长模式 = 文档指定，如 a,a,a,b,b 或 a,a,b,c,b）；
5. 周期域按 W, H 平移覆盖后，世界坐标↔格、邻接、环绕查询自洽；
6. 整体旋转到方向规范后仍满足 1–5。

（文档内所有"实验结果"均来自项目现有工具在本机上的实际运行；数值为近似值。）
