## laves_33434（完成）
- 旧规格短边在 **45°/135°**；新方案要求「短边水平或竖直」且块定义「一条竖直短边的边邻+点邻共 4 块、偶列上移」。
- 把五边形转到**竖直短边**后，点阵的轴对齐纯平移域 = `(2√2, 2√2)`，**B 4→8**，8 格域。
- 验证：短边 0°/90°、单格面积 1.0、域面积 8、**40 边 0 异常邻接**、覆盖无空洞。
- 生成逻辑在 `tools/gen_laves_specs_v3.py::build_laves33434`。

## laves_4612（未完成，回退旧版）
新方案文档块：6 个 30/60/90 三角 → 直角梯形（3 三角 30° 顶点共点、中部三角与一侧邻长直角边、另侧邻斜边）→
2 梯形斜边重合 → 小矩形；4 个 2×2 拼成大矩形（24 格），左上/右下=A、右上/左下=左右镜像。

**尝试与失败**：
1. **纯平移复制小矩形**（用户点明"任意矩形可密铺"）：无缝隙，但三角斜边只{90°,150°}，**丢了 30°一族**（不完整）。
2. **2×2 奇偶镜像**：斜边补全 {30,90,150}，但**相邻关系错乱**（72 边里 16/24 格邻接数为 0 或 2）——
   镜像绕矩形**中心线**时，上下/左右接缝两侧三角边未逐边闭合（外形可密铺≠内部三角邻接对）。
3. **校验工具**：之前用"粗覆盖采样"误判为无缝隙，实际逐边邻接检查才暴露问题。

**最终**：还原 `git HEAD` 的 laves_4612 + 方向纠偏 `rot90` → B=24、W/H=`3.722419×6.447419`、
hyp {30,90,150}、**72 边 0 异常邻接**、覆盖无空洞。即**原方向纠偏版本身就是既密铺又邻接正确的形态**，
本轮未能重排出同时满足"邻接干净 + 三族齐全"的新版。

## 关键教训（供后续）
- 判据要用**逐边邻接**（每条边恰有 1 邻居），不能只看面积/粗覆盖。
- 镜像只是"外形可密铺"不足以保证内部三角邻接闭合——须按**共享接缝**对齐镜像轴，而非各自矩形中心线。
- 需要能同时给出 6 三角小矩形的**确切镜像轴/排布**才能重排出邻接干净的新版 laves_4612。
